# 三车悬挂测试场

运行仓库根目录的 `./build/project_Demo/vehicle_playground/demo_vehicle_playground`，打开真实 GRE / YMGUI / SDL 窗口。三辆车同时存在，切换驾驶时其他车停住，但继续计算竖直悬挂运动。

| 按键 | 功能 |
| --- | --- |
| 1 / 2 / 3 | 履带车 / 两差速轮加后万向轮 / 四轮悬挂车 |
| W / S | 前进 / 倒车 |
| A / D | 左转 / 右转；履带和三轮可原地差速转向 |
| Space | 刹车并退出自动测试 |
| T | 自动过山包往返，再按停止；启用时重置车辆 |
| C | 跟随 / 全场俯视 / 悬挂侧面近景 |
| V | 当前车身线框，便于看内部零件 |
| H | 凸 Mesh / AABB 检测切换，重置车辆 |
| P / R / Esc | 暂停 / 全部重置 / 退出 |

默认选中红色四轮车。按 **T，再按两次 C**，观察左右错开的山包引起的前后俯仰、左右侧倾和独立悬挂压缩。状态栏显示车速、俯仰/侧倾角、接地轮数和四角压缩量（FL/FR/RL/RR，单位毫米）。数字按键切车后按 T，可体验对应路线。

## 模型

- 黄色履带车：左右差速、六个弹簧阻尼支撑点、两条连续转动的履带。使用履带行程驱动履带块，避免轮子转角回绕造成动画跳变。
- 蓝色三轮车：复用差速运动学与带拖距的被动后万向轮，三个短行程支撑点适应小山包。
- 红色四轮车：前轮 Ackermann 转向，四个独立弹簧阻尼支撑点；车身有质量、竖直速度以及俯仰/侧倾惯量。接触力计算包含弹簧、阻尼、行程末端缓冲块及重力，离地时不施加拉力。轮子、减振杆和弹簧圈跟随行程变化。

悬挂使用世界竖直方向的高度场射线接触，固定 1/120 秒积分。水平驾驶仍是运动学，轮胎没有独立非簧载质量、侧滑/抓地力和驱动力分配；履带块是动画而非相互连接的刚体。俯仰/侧倾限制在约 ±34 度，目前用于小游戏和悬挂观察，不模拟完整翻车动力学。

## 地面高度图

地面是 **24 × 24 米、65 × 65 个采样点**的高度场，间距 0.375 米。GRE 将它显示为 8192 个三角形，分成 64 块。物理接触采用完全相同的三角划分和重心插值，而不是只改变地面颜色或法线。

默认程序生成三条路线：履带路线较宽的丘陵、三轮路线较低的小包、四轮路线左右错开的交叉轴山包及后方宽坡。停车区是平地。

支持 **P5 二进制灰度 PGM，65 × 65，最大灰度 255**：黑色对应 0 米，白色对应 1.2 米；左上角对应世界 `(x=-12,z=-12)`。示例地图在 `Resource/vehicle_playground/heightmap.pgm`。

从仓库根目录执行（资源使用绝对路径）：

```sh
./build/project_Demo/vehicle_playground/demo_vehicle_playground --heightmap "$PWD/Resource/vehicle_playground/heightmap.pgm"
./build/project_Demo/vehicle_playground/demo_vehicle_playground --export-heightmap "$PWD/my_heightmap.pgm"
```

可以编辑该灰度图后重新加载。建议保留车辆起始位置 `z=-6.4` 附近的平地，并使用平缓坡面。

## 碰撞与代码分层

车辆零件与围栏/障碍使用现有 YMPME 的过滤 → AABB → 可选凸 Mesh 精检测。每辆车的零件共享不同的 `ignoreAssembly`，因此本车内部忽略，车辆之间仍检测。履带外侧使用两个保守盒体代理。侵入环境时对整车本步水平移动和转向回退；当前不做车辆间动力学推挤或碰撞角冲量。

地形是可凹的高度场，单独处理轮地接触，**不把整片地面当成凸 Mesh**。H 控制车辆/障碍的 Mesh 精检测，轮地高度场接触始终保留。车底触地和任意障碍物顶面的悬挂接触尚未实现；高凸包可能穿入车底，应以现有测试场的平缓坡面为主。

- `terrain.c/h`：高度场、三角采样、PGM 读写。
- `vehicle.c/h`：三类车的驾驶和悬挂，不依赖 GRE。
- `playground.c/h`：GRE 网格、零件碰撞、整车移动和相机。
- `main.c`：窗口、键盘、状态栏与冒烟测试。
- `test_vehicle.c`：静态载荷、转向、坡面压缩、离地与高度图回归。

完整 GRE 窗口构建运行 `ctest --test-dir build --output-on-failure`；新增 `ympme_vehicle_suspension`、`ympme_vehicle_playground` 两项。

## 模型复用

本 Demo 链接 `YMPME::vehicle`，复用 DRIVE/TERRAIN/SUSPENSION。物理采样在模型层，PGM 读写和 GRE 地形网格在 Demo。 构建时需启用相应的 `YMPME_MODEL_*` 开关。
