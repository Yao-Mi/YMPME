# 双轮物理履带台架

直接运行 `build/project_Demo/track_lab/demo_track_lab`。没有外部资源、启动脚本或桌面入口；窗口、输入和计时通过 GRE host。装配全部在本 demo 内，没有新增库 Model，也没有改变旧 vehicle_playground 的动画履带。

## 物理组成

- 40 个独立刚体履带块，40 个转动关节连接成闭环。块节距 0.16 m，质量每块 0.12 kg；初始共享锚点，只有初始化使用环形排布，运行时不覆写履带位置。
- 主动轮通过世界铰链固定轮轴，以限矩速度电机驱动；默认 1.5 rad/s，上限 2 N·m，有起动斜坡。
- 从动轮通过铰链连接滑动架；滑动架沿 X 轴移动，由预载弹簧和阻尼张紧。默认预载 50 N、刚度 350 N/m、阻尼 12 N·s/m，行程 −35～75 mm。界面的 spring 是张紧机构外力，并非某一节履带的精确内张力。
- 摩擦驱动轮与履带，地面承接下垂链条。两侧无摩擦导向面限制横向跑偏，蓝色线框表示导向面所在位置。
- DYNAMICS 每步共同求解关节与接触，然后积分一次；480 Hz、64 次迭代。只有显示帧更新 GRE 网格。

这是**共面摩擦传动台架**：轮的碰撞使用球形代理，在带侧向导向的共面接触下近似圆截面；轮的显示为 48 段圆柱，惯量为均匀圆柱公式。它不是三维圆柱碰撞，也没有齿形啮合。这样关闭摩擦时不会由多边形棱角产生额外的几何驱动。后续整车的宽轮、侧壁、主动轮齿形需要实际几何碰撞。

履带块与轮、地面、导向面检测接触；本台架过滤所有履带块之间的接触，因此不用于折叠履带的自碰撞、脱轨或堆叠。该简化不忽略轮与履带的接触。小量接触穿透是离散冲量求解的误差，并非绝对零穿透保证；没有 CCD，不用于高速冲击。

## 操作

| 按键 | 功能 |
|---|---|
| ↑ / ↓ | 增减带符号的目标轮速，范围 −3～3 rad/s |
| D / S | 反转目标速度 / 目标归零（电机仍制动） |
| M | 电机开关；关闭后不施加电机力矩 |
| F | 摩擦 1.1 / 0 对照；零摩擦不代表链条没有重力晃动 |
| [ / ] | 调小 / 调大张紧预载，范围 0～100 N |
| Space / N | 暂停 / 单物理步 |
| R | 重置姿态和物理参数 |
| C / V / H | 正视与斜视 / 线框 / 接触和锚点标记 |
| Esc | 退出 |

绿色表示受载履带块，绿色短线为作用在履带上的接触法向；黄色十字是铰链锚点，红色标记同一节履带以便追踪。面板提供轮速、履带块平均速率、电机力矩、张紧机构载荷和行程、最大关节误差、接触穿透量与物理步耗时。

耗时是本机实测，界面 60 Hz 估算为每帧 8 个物理步，未包含渲染。超载时限制追赶子步数并放慢仿真，避免无限积压。需要大量车辆时，旧 demo 的动画履带结合简化车体受力更经济。

## 构建与验证

已有 GRE 构建开启 DYNAMICS 后：

```console
cmake --build build --target demo_track_lab test_track_lab -j 4
./build/project_Demo/track_lab/test_track_lab
```

独立、不依赖 GRE 的验证构建（从 YMPME 根目录执行）：

```console
cmake -S project_Demo/track_lab -B build/track-headless -DCMAKE_BUILD_TYPE=Release
cmake --build build/track-headless --target test_track_lab -j 4
./build/track-headless/test_track_lab
```

测试覆盖 10 秒正转、反转、增大张紧预载、关闭电机及重新初始化后的 10 秒零摩擦对照，检查闭环误差、穿透、横向偏移和从动轮响应。首次 Release 实测约 0.56 ms/步，最大铰链误差及接触穿透约 0.63 mm；这些数字只代表此台架和测试参数。窗口测试通过 GRE 输入接口验证暂停、单步、切视角、线框、反转、摩擦、电机和重置。
