# hand_low 皮肤反馈实验台

运行 `build/project_Demo/hand_skin/demo_hand_skin`。此演示复用YMSKE的hand场景源码与低模资源，不复制或修改YMSKE，不改变其现有高模演示配置。

- 模型固定为 `YMSKE/Resource/hand_low`，1345渲染顶点、1698三角面、16骨骼、15个PME转动关节；长度从SKE显示单位除以10转换为米。
- 每个非退化三角面中心为一个曲面测力单元，面积取当前蒙皮三角面积。UV拆点只分割三角形，面积不重复累计。
- 白色球线框为半径15mm的运动学压头，默认对手掌按入目标3mm。选择新区域会恢复张手并设定新的世界压头位置，随后压头固定在世界，不会跟随手指移动。按压深度是相对于选区时参考点的目标，实际穿入量另外显示。
- 曲面模型输出弹性/阻尼/摩擦载荷，SurfaceTactile读取压力/剪切力。通过三角面顶点的平均蒙皮权重，把接触力施加到各PME刚体的同一接触点，Joint_Step求解后经SKE映射和蒙皮再交给GRE。
- 每步循环：上一姿态蒙皮位置 → 曲面接触载荷/测力 → 指节受力与电机求解 → PME→SKE同步 → GRE持久顶点更新。物理240Hz，界面约60Hz，独立固定步长累积；单帧最多追赶50ms。图上数值/颜色为最后一个物理子步输入载荷，几何为该步末姿态。

| 操作 | 功能 |
|---|---|
| 0–5 / 区域按钮 | 手掌、拇指、食指、中指、无名指、小指 |
| + / - | 按压深度每次变化0.5mm，范围退出10mm到按入6mm |
| H | 压力热图/原皮肤贴图 |
| I | 球形压头六维测力噪声 |
| Z | 下一成功采样去皮；ABS变REL，仅改变测力读数，热图仍为真实模型压力 |
| O / F | 张手 / 半握目标，实际角度由PME关节电机与接触共同决定 |
| B | 骨架叠加 |
| 方向键 / 滚轮 | 转动视角 / 缩放 |
| Space | 暂停；按压/去皮将在下一物理步更新 |
| R / Esc | 恢复默认手掌按压与绝对测力 / 退出 |

颜色范围固定0..1000Pa，不随每帧峰值变化；每个三角形的压力按面积加权到其顶点后插值，仅用于可视化，不是物理载荷扩散。探头总力带20Hz低通，可加均匀噪声和去皮；侧栏显示法线方向测力、压力峰值、命中单元、估计反力矩及选区末节的目标/实际角度和关节反力。

接触目前是**采样曲面的柔顺近似**，不是任意物体精确网格碰撞抓取；缺少手指自碰撞、皮肤组织局部凹陷、真实接触面积扩散、连续碰撞和拇指多轴对掌。手指因接触发生运动不等于软组织变形。快速移动/很小探头/粗网格可能漏检或产生离散突变。压力上限显式报告，实验参数不代表真实人体组织标定。

## 构建与依赖

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DYMPME_BUILD_GRE_DEMO=ON -DYMPME_GRE_ROOT=../0502_YMGRE \
  -DYMPME_BUILD_HAND_SKIN_DEMO=ON -DYMPME_SKE_ROOT=../YMSKE \
  -DYMPME_ENABLE_JOINT=ON -DYMPME_MODEL_SKIN=ON \
  -DYMPME_SENSOR_TACTILE=ON -DYMPME_SENSOR_FORCE=ON
cmake --build build --target demo_hand_skin -j8
```

SKIN模型和SurfaceTactile接口均可在无GRE/SKE环境下独立编译。只有本demo启用SKE桥接和GRE宿主。常规采样、关节、蒙皮与GRE更新零堆分配，文件加载与窗口宿主不在此承诺范围。

测试覆盖六个按压区域、载荷随深度变化、反作用力/力矩守恒、去皮、释放、关节反馈、窗口实际键盘/点击事件及热图切换。可用 `--headless` 导出GRE画面，`--smoke-test` 自动交互后退出。

## 对YMSKE的后续建议

现有骨架、逆绑定、CPU蒙皮及PME/GRE桥接足够支撑此实验，无需把皮肤接触塞进SKE。后续按需求增加通用动画采样/混合、IK、物理绑定配置的资源存档；PME侧优先补旋转刚体的接触流形和摩擦求解、球关节/多轴手指以及手指内部过滤。先形成准确的物理接触，再扩展真实皮肤压力分布与组织响应。

## UV展开力图

窗口右侧新增512×512实时UV图，复用hand_low已有UV，不改模型/贴图文件，也不重新展开。左侧三维图与右侧UV图读取同一批物理测力单元；按压与指节运动时，UV位置固定在材料表面，不随观察相机移动。

- 默认显示每个三角测力单元的压力，范围固定0..1000Pa。按T或“Pa/N”按钮，切换为每单元法向压缩力，范围0..0.10N；左侧三维热图仍为压力。两种模式都有明确色标，超过上限仅在颜色上饱和，不截断读数。
- 点击UV表面会高亮对应三角单元，并显示压力Pa、法向力N和该物理采样时刻的真实三维面积cm²。选择保持在同一材料单元，随后采样更新数值。点击空白清除选择。图中的UV采用现有GRE纹理坐标：u向右、v向下，与资源BMP采样一致，没有额外上下翻转。
- UV图显示原始分片恒定测力值；三维热图仍采用面积加权到顶点后的平滑插值。因此二者使用相同物理来源与压力色标，但边缘平滑程度不同。UV面积不等于真实皮肤面积，不能对图上像素直接求和作为总力；N模式中的同一单元只是覆盖多个显示像素，物理载荷始终只计一次。
- 当前资源在512×512采样时有少量重叠UV像素及亚像素单元，窗口报告数量。重叠像素显示品红，点击拒绝给出唯一单元读数；没有独立像素的细小单元仍参与物理测力和总力，图上无法单独辨认。以后用于完整传感器数据导出时，应使用测力单元数组，或制作无重叠、足够分辨率的专用传感器UV图集。

UV像素→测力单元索引只在初始化时光栅化、缓存，帧更新仅查表着色；不修改PME物理、YMSKE或GRE库，正常更新无堆分配。测试覆盖UV点击位置、重叠拒绝、相机旋转不改变UV图、Pa/N切换不改变物理载荷、退出接触后清空热区、实际鼠标点击与按键操作。
