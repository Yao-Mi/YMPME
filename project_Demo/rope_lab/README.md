# 通用绳索模型演示

在根目录执行 `./build/project_Demo/rope_lab/demo_rope_lab`。构建时启用 `YMPME_MODEL_ROPE=ON`；程序沿用软件 SDL 显示配置。

- 左：33 节点、两端固定，从直线零初速释放，自然下垂至平衡；初期会有绳波。
- 中：17 节点、2.1m 长的 U 型绳，锚点位于 (0, 1.3, 0)，2kg 重物质心位于绳端 (0.5, 1.3, 0)。绳子先下垂再向上折回，重物和绳身从零初速释放，靠重力逐渐拉直。
- 右：33 节点、末端按三维轨迹移动；可松开末端观察响应。

打开或 Home 重置后先暂停在初始 U 型，按 Space 释放 / 暂停。中间视图默认四分之一速度，S 切换 0.25x / 1x；只改变该视图的时间推进，不减小重力。N 单步，K 推动绳子，T 开关右侧锚点运动，P 释放 / 固定右侧绳的末端，C 正视 / 斜视，Home 重置，Esc 退出。

三实例共用 `MODEL/ROPE` 求解器，单实例状态与缓冲独立。GRE 适配缓存每条绳的一份网格，物理子步结束后每个显示帧只同步一次；重置复用已有网格和相机。UI 的 Sync 包含绳网格同步和两端标记位置更新；Draw 为 GRE 绘制耗时；Physics 是三条绳每次更新的合计耗时（左右 1/120s，中间按所选速度缩放）。本演示采用 64 次约束迭代，性能会随配置和机器变化。

模型局限、接口和裁剪方式见 [ROPE 说明](../../YMPME/MODEL/ROPE/README.md)。本 Demo 不包含绳身碰撞或缠绕。
