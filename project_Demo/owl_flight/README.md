# 猫头鹰键盘飞行

基于 `flight_playground` 的鸟类飞行动力学另做一份单猫头鹰 demo。使用 YMSKE `Resource/owl` 的原生网格、贴图、骨骼及拍翅动画；默认键盘手动飞行，从 18 m 高、10 m/s 初速开始。

直接运行 `build/project_Demo/owl_flight/demo_owl_flight`。资源路径在构建时使用绝对路径，从文件管理器双击或其他工作目录启动均可；不需要启动脚本或桌面安装项。可用 `--assets /path/to/owl` 指定资源目录。

| 按键 | 操作 |
| --- | --- |
| W / S | 增加 / 减少振翅推力（松开回到巡航推力） |
| A / D | 左 / 右滚转转弯 |
| ↑ / ↓ | 抬头爬升 / 低头俯冲 |
| Q / E | 左 / 右协调转弯 |
| G | 振翅 / 展翼滑翔，平滑过渡 |
| T | 自动盘旋定高 / 键盘操控 |
| C | 跟随、俯视、前侧三个视角；前侧能看到脸 |
| V | 阵风开关 |
| X / B | 线框 / 主骨骼 |
| Space / N | 暂停 / 暂停时单物理步 |
| R / Home | 回到空中初始位置并恢复振翅，关闭阵风；保留暂停和操控模式 |
| Esc | 退出 |

按键可组合，按住生效、松开解除；窗口失去焦点会清除方向键状态。状态栏显示操控模式、振翅/滑翔、风、落地状态以及高度、空速、垂直速度、升力和推力。落地后用 R 重新开始。

PME `YMPME::aircraft → YMPME::flight` 负责 SI 单位下的载荷、位置和四元数姿态积分，物理步长 1/240 s；YMSKE 的文件导入与 GRE 网格绑定直接复用原猫头鹰 scene。应用在骨架根姿态中合成飞行位置、旋转及统一缩放，每个显示帧只做一次蒙皮更新，无二次网格复制或逐帧文件加载。模型原翼展约 6 单位，缩放为约 2.7 m。

拍翅周期同步现有 PME 鸟类模型的翼相位（2.2 Hz），因此播放速度高于资源原始 1.32 秒循环。初始化从动画采样中选择最大横向翼展作为滑翔姿态，停翅/恢复时进行约 0.15 s 的矩阵过渡。动力学仍是原 Eagle 等效翼面预设，尚未按猫头鹰物种重新标定；动画不反向求解羽毛空气动力。

地面提供现有模型的平面落地支承。棋盘地面和树木用于速度/高度参照，树木不参与碰撞。低空速时沿用原模型的防失速俯仰修正，不支持悬停。

## 构建与测试

在 YMPME 根目录：

```sh
cmake -S project_Demo/owl_flight -B build/owl_flight -DCMAKE_BUILD_TYPE=Release
cmake --build build/owl_flight -j8
ctest --test-dir build/owl_flight --output-on-failure
```

独立构建使用四槽权重，不影响六槽人体 demo 的构建。可配置 `YMPME_GRE_ROOT`、`YMPME_SKE_ROOT` 和 `OWL_FLIGHT_OUTPUT_ROOT`。

`owl_flight_dynamics` 检查飞行位移、转向、滑翔、根姿态与物理平移一致、非法输入不改状态以及姿态/蒙皮/渲染的零帧分配；`owl_flight_window` 使用 GRE 按下/松开事件检查手动输入、暂停、单步、滑翔与恢复、自动飞行、视角、风、骨骼/线框、失焦清键、重置和退出。
