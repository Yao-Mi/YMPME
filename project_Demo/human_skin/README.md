# 人体皮肤传感器 demo

运行 `./build/project_Demo/human_skin/demo_human_skin`。使用 YMSKE `Resource/human` 的原生网格、骨架和完整六槽权重，通过 GRE 窗口显示全身接触反馈。原始 human 资源和演示源码保持不变。

默认演示**左手接近胸腹、沿体表滑动、抬手离开**，10 秒一循环。肩—肘两段 IK 和手腕朝向控制驱动同一具人体的蒙皮；接触检测修正手的目标位置，限制手部采样点穿入体表。手和身体都显示 RGB 法向/双切向反馈。

按 **S** 切回原球形探头模式；此时点击 3D 身体可移动探头，仍支持九个部位及关节摆动。两种模式共用皮肤传感器和骨骼载荷汇总。自体模式默认显示 PME 等面积传感器布局：头、躯干、双手、双腿和双脚共用一张全身图；每个三角形占相同显示面积，优先连接邻面。直接执行二进制，不安装桌面或菜单入口。

## 传感器数据

- `rig.patches[]`：当前蒙皮三角面片的世界位置、单位法线、速度和真实面积；速度来自同一面片位置的时间差分。
- `rig.forces[]`：每个面片的三维世界接触力（N）。
- `rig.taxels[]` / `rig.touch`：复用 `YMPME_SurfaceTactile_Measure`，提供压缩法向力、切向力、压力；自体模式加上面片力矩补偿后，`touch.wrench` 是关于左腕的全体皮肤总载荷（内部接触应抵消）；探头模式参考点为球心。
- `rig.self.result.sourceWrench/targetWrench`：自体模式的手部/胸腹成对载荷，关于同一左腕原点（世界坐标轴），合力和合力矩为零。
- `rig.self.moments[]`：自体接触力作用于实际共同接触点，补偿到各面片中心的力矩；和 `forces[]` 一起汇总可保持世界力矩守恒。
- `rig.reaction.probeWrench`：自体模式为手部接触 wrench；探头模式为皮肤给球的反作用 wrench（关于球心）。
- `rig.loadReading`：复用六维 ForceDevice，提供滤波、量化和去皮后的手部或探头接触反馈。
- `rig.boneLoads[63]`：按每个三角形三个顶点的**全部六槽权重**汇总骨骼载荷，力矩关于当前骨骼原点；不是关节约束求解器的 reaction。对所有骨骼转换到同一参考点后求和，和皮肤总 wrench 一致。
- `rig.localForces[]`：供显示的 Fn/Fu/Fv 分量，在 Render 时更新。物理采集应读取同一步的 `forces/taxels/touch`，不从截图反推浮点力。

采样固定 **120 Hz**，单位米、秒、牛顿、帕、牛顿米。沿用演示约定，每 10 个 GRE 模型单位为 1 m；未将资源强制缩放为某个成人身高。三角面片面积在变形后重新计算，UV 像素面积不参与力计算。暂停时读数保持上一采样。

## RGB 与 UV

三角对照模式显示**一张 512×512 PME 全身等面积传感器图**，包含 3584 个面片，头、躯干、双手、双腿、双脚均在其中。所有三角形大小相同，图块间隔为 0.04 个三角边长；优先连接相邻面片。绑定姿态初始化一次，动作不会重排 UV。9/N 只在同一张图中放大当前手部/胸腹受力面片，U 恢复全图，不再创建分区视口。

全图使用统一颜色量程，点击面片读取真实浮点力。图上的面积、细网格和缩放都不参与物理计算。与新 [地面运动 demo](../human_ground/README.md) 共用完全相同的全身面片映射。

各模式均为 **R=法向压缩力、G=沿 UV 的 U 切向力、B=沿 UV 的 V 切向力**。U 向右、V 向下，镜像岛保留各自坐标方向。自体模式默认 R 为 0～0.04 N、G/B 为 ±0.02 N，原探头模式为 R 0～4 N、G/B ±2 N，均编码为 0～255；**128 表示零切向力**，所以无接触处为 `(0,128,128)`。显示截断只影响颜色，`RGB clip` 显示截断面片数；点击读数保留原浮点值。颜色量程不会自动逐帧变化。

V 切换 UV 时，显示的切向坐标基随之改变，实际世界力与探头轨迹不变。探头的滑动控制始终使用自动 UV 的局部方向。模长图以每面片三维力模长着色，压力图使用法向力除以实际面积。3D 用邻接面片面积加权平滑颜色并带照明，用于观察位置；UV 图用于分量判读。三维网格没有因为自动 UV 重新拓扑或更改蒙皮索引。

直接复用 GRE 编辑器的 `scene_uv_atlas.cpp` / xatlas，实现同样的保持比例自动展开。绑定姿态初始化一次，目前生成 **48 个 UV 岛**。2048×2048 的像素→面片缓存中，3584 个皮肤面片全部可寻址，无重叠、无遗漏。窗口只生成 512×512 的 UV 视口，支持鼠标局部放大，避免逐帧处理整张高分辨率贴图。GRE/原 UV 和单张 PME 全身布局共三份缓存约 48 MiB；固定 512×512 面片索引额外约 0.5 MiB，属于桌面 demo 静态缓存；物理、传感器核心没有增加这项内存需求。全图缩小显示时很小的面片仍可能不可见，请在对应区域放大或直接点击 3D 表面。

选中边框、空白区域是界面标注，不能当作传感器 RGB 数据。原 UV 的重叠区域以洋红色标记并拒绝唯一面片拾取。

## 模型边界

这是**运动学人体的皮肤载荷测量与骨骼载荷汇总演示**。人体姿态和探头轨迹均由 demo 控制；传感器结果没有反向驱动人体骨骼动力学，也不是布娃娃、软组织 FEM 或关节力控仿真。骨架中的前 11 个节点是源资源控制手柄，不作为普通身体关节按钮展示。

接触复用可裁剪 `YMPME::skin_contact` 的 `YMPME_SkinContact_Sphere`：AABB 粗筛后进行球与表面采样点的弹性地基接触，含压缩阻尼、库仑上限切向黏性摩擦和显式压力上限。不是连续/逐三角形碰撞；单个面片内视为均匀载荷，快速滑动、较粗三角形会影响精度。两侧反力守恒；球形探头模式下人体保持设定姿态。`touch.approximate` 与探头反馈的近似标记均保留。

## 自体接触的实现与边界

`YMPME_SkinSelfContact_Solve` 在 PME 的 SKIN 模块内实现，输入只有米制三角面、表面速度/面积与 32 区域过滤矩阵。处理顺序为**区域过滤 → 区域 AABB → 点/三角形 AABB → 最近三角形接触**。每个手部三角形使用中心和三个顶点采样，每个采样点只取最近的允许目标面，面积权重各 1/4。法向弹性/阻尼与受库仑上限限制的切向黏性摩擦产生载荷，并在同一接触点向双方分配等大反向力及力矩。无堆分配、无 SKE/GRE 依赖，可随 `YMPME_MODEL_SKIN` 裁剪；原 Sphere API 和核心 ABI 不变。

此 demo 只启用**左手（含指节）—胸腹前表面**碰撞对。按绑定姿态和蒙皮权重预分区，同手内部、手腕连接处、相邻肢体等均未启用；G 演示过滤。不是全身任意部位的完整自碰撞，区域/拓扑过滤需由应用定义。相同顶点位置但属于不同 UV 岛不会被当作不同空间表面。

接触采用 **8 mm 虚拟柔顺层**，IK 将最大采样压入量限制在约 **4.1 mm**；这是接触容差，未把皮肤网格做软体形变。IK 反馈是受碰撞限制的运动学姿态修正，尚未接入关节动力学/力矩电机，也未实现完整人体关节限位。胸腹不被推走。`IK stop` 为目标修正距离，`error` 为两段手臂 IK 的腕部目标误差。

这版不是连续碰撞检测、完整三角形—三角形/边—边求解；大时间步、超过搜索范围的瞬间位姿变化、粗面片之间的交叉仍可能漏检。摩擦使用面片中心的平均速度，未建静摩擦历史或逐点角速度场。当前动作使用固定 120 Hz、小幅连续轨迹；每步复用上一修正位置减少重复蒙皮。手与身体法向力的标量总和可能不同，因为各自表面法线不同；世界向量合力和统一参考点的力矩必须抵消。RGB 显示可用 9/N 分别检查两处。

## 构建与独立性

人体需要 **YMSKE_MAX_INFLUENCES=6**，手部演示是 4。两种 ABI 不混合链接；此目录是独立 CMake 工程，构建目录为 **YMPME/build/human**（Release），保留现有 build 的四槽配置。不要把人体工程配置进旧 build 目录。

```sh
cmake -S project_Demo/human_skin -B build/human \
  -DCMAKE_BUILD_TYPE=Release \
  -DHUMAN_DEMO_OUTPUT_ROOT="$PWD/build/project_Demo" \
  -DYMPME_GRE_ROOT=/home/yaomi/文档/0502_YMGRE \
  -DYMPME_SKE_ROOT=/home/yaomi/文档/YMSKE
cmake --build build/human -j8
ctest --test-dir build/human --output-on-failure
```

本演示复用 YMSKE human 的加载、蒙皮和姿态控制，PME 的 SKIN、SURFACE_ATLAS、TACTILE、FORCE，以及 GRE 的窗口、渲染和原比例 UV。新的等面积布局代码独立位于 `MODEL/SURFACE_ATLAS`，默认关闭，不依赖 GRE/SKE。手部与人体共享 `project_Demo/common/force_channels` 的局部三维力分解、RGB 编码，相关依赖只在 demo 层。PME 核心和传感器仍不依赖 GRE/YMSKE；此演示完全不进入默认核心构建。

`--headless` 输出 `human_skin.ppm`；`--smoke-test` 自动验证窗口事件。测试覆盖六槽数据保留、九个区域按压、四向切向力、反作用 wrench/骨骼汇总守恒、去皮与撤离、姿态更新、自动 UV 与视角/轨迹独立性、UV 放大拾取、3D 深度拾取和帧内零堆分配。内存检查可使用独立构建选项 `-DHUMAN_SKIN_SANITIZERS=ON`。

自体回归覆盖完整接近/持续滑动/离开、8 mm 接触层与姿态修正、双方 RGB、过滤恢复、世界力/力矩及骨骼载荷守恒、显示选项不影响接触、去皮、零帧内分配；窗口测试包含 S/D/G 事件和旧探头流程。

当前全身布局：3584 面 / 164 图块，保留 3499/5376 条邻接边。全部面片在 2048 缓存和固定 512×512 观测图中均可寻址，没有内部重叠。接缝不保证全局最少；详见 [SURFACE_ATLAS](../../YMPME/MODEL/SURFACE_ATLAS/README.md)。

## 智能体观测

`observation.h` 提供 `HumanSkin_Observe` 与 `HumanSkin_ObservationMap`：固定全身 RGB、逐面片浮点 (Fu,Fv,Fn) N、仿真时间戳和像素→面片 ID。不受相机、UV 缩放、选中框、网格、显示模式或 C 显示增益影响。观测量程显式保存在 `contactView.observationNormalRange/observationTangentRange`，所有面片共用；本演示默认 0.1/±0.05 N，地面演示为 20/±10 N。无接触的有效皮肤 RGB=(0,128,128)，背景=(0,0,0)、面片 ID=65535。

二进制位置统一在 `build/project_Demo/human_skin` 和 `build/project_Demo/human_ground`；编译缓存/库位于 `build/human`，六槽 ABI 与其他 demo 独立。旧 `build-human-skin` 目录不再使用。无桌面入口、无启动脚本。


全身小图已使用 PME 轮廓装箱，将小图块插入大图块空洞；保持所有邻接和统一三角尺寸。面积利用率约 39.7%（上一版约 25.6%）。只在启动时排布，动作期间映射固定。此次布局升级改变像素位置；已有智能体数据应重新导出对应的面片 ID 图。


## 默认拓扑网格

现在默认显示 **64×64 拓扑网格**，3584 个面片各占一格，512 格为空；窗口放大为 512×512 便于看清，不将多个面片合并到一格。V 切网格/三角对照，Y 在网格中切身体部位配色，9/N 在当前图中聚焦手/胸腹，U 恢复网格全图。

新增 `HumanSkin_ObserveGrid`、`HumanSkin_GridObservationMap`、`HumanSkin_GridNeighbours` 提供独立于显示模式的原生 64×64 RGB、独占面片 ID 和真实拓扑邻接。原 `HumanSkin_Observe` 的三角 atlas 输出保留。映射生成后固定，受力切向基沿用同一三角 atlas，不随方格排布改变。详见 [地面 demo 的观测说明](../human_ground/README.md#拓扑网格观测默认)。

### 栅格拾取测试

点击 **PICK TEST OFF** 开启测试，再点击右侧栅格，左侧人体对应的唯一三角面片会以亮黄色描边和填充线高亮，并跟随动画。采用透视叠加，因此背面或被遮挡的面片也能定位；此颜色不代表受力。信息栏显示面片编号和力。点空格清除选中，再点按钮关闭高亮。仅影响显示，不改变传感器 RGB、力数据或 face/cell 映射。

### 双侧接触可视化

默认开启 **CONTACT MARKS ON**：实际受力的手部和躯体面片以白色描边标记，三维描边可透视看见掌面；栅格白边表示接触，内部 RGB 仍是线性的真实力编码。点按钮可关闭。手部网格细，单面力较小，因此同一力色标下红色通常比躯体弱；可用 C 调整显示量程、9 放大手部，或 T 切换压力视图。白边不会写入智能体观测数据。

### 64×64 面积缓存

`HumanSkin_GridAreas(&rig)` 返回与 `HumanSkin_GridObservationMap` 完全对齐的 `const float[4096]` 视图（行优先、左上原点、m²）。空格为 0，非空格为初始化姿态的整片三角面积。数组由 rig 持有，初始化时复用已有面片面积写入一次，之后不随蒙皮变形更新；读取不分配内存、不重新计算几何。它占用 16 KiB（32 位 float）；同一实例中面积和 ID 映射固定，可保存一次后重复使用。

```c
const float *area = HumanSkin_GridAreas(&rig);
const uint16_t *ids = HumanSkin_GridObservationMap(&rig);
size_t cell = y * HUMAN_GRID_OBSERVATION_SIZE + x;
float meanPressurePa = area[cell] > 0 ? local[ids[cell]].z / area[cell] : 0;
```

示例中的 `local` 来自同一帧 `HumanSkin_ObserveGrid`，其 z 为 Fn（N）。这里得到以初始参考面积为基准的整片平均压强，不是部分接触区域的局部压强。按当前约定忽略蒙皮导致的面积变化；后续每帧只更新力即可。

导出新增 `skin_grid_area_m2.csv`：无表头、64 行×64 列，以 9 位有效数字保存 float，坐标顺序与 ID/RGB 图一致。`skin_grid_metadata.json` 记录面积文件、单位、定义和空格值，时间沿用同一观测的 `time_s`。
