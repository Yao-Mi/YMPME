# 三轮差速小车

在 YMPME 根目录运行 `./build/project_Demo/three_wheel_car/demo_three_wheel_car`，打开 GRE/YMGUI/SDL 驾驶窗口。

- **W / S**：前进 / 倒退；**A / D**：左转 / 右转。单独按 A/D 时两轮反转，原地旋转。
- **Space**：按住刹车；**左 Shift**：加速；松开方向键时轮速逐渐降到零。
- **H**：Mesh / AABB 碰撞切换并回到起点；**C**：近距离跟随 / 全场俯视；**P**：暂停 / 继续；**R**：重置；**Esc**：退出。
- 开过场地中的五块绿色检查点；橙色障碍和蓝色围栏有碰撞。收集全部后显示 COMPLETE。
- 底部显示左右轮缘速度、万向轮摆角、检查点进度、接触次数和模拟时间。

## 模型

左右驱动轮位于同一轴线上，轮距 1.04 m、半径 0.26 m；车身后部有半径 0.13 m、拖距 0.14 m 的万向脚轮。`v=(vL+vR)/2`，`omega=(vL-vR)/track`。前向 +Z、上向 +Y，正 yaw 向右。

目标轮速经过加速度限制，在 120 Hz 步进中积分。万向轮依照枢轴速度和拖距被动转向；倒车时会翻转回正。GRE 每帧从保留的局部顶点重建所有部件的位置和面法线，轮毂色块展示车轮自转。

这是**平地差速运动学演示**，不是完整车辆动力学。现在按实际 GRE 局部顶点给车身、驱动轮和万向轮分别建立闭合凸 Mesh；姿态随零件旋转。检测顺序为过滤 → AABB → 可选 Mesh SAT。车内装配体 ID 相同，因此内部配对在粗检测前忽略；环境使用实际尺寸 Box。

H 在 Mesh 与 AABB 模式间切换；为避免模式切换后卡进障碍，同时回到起点。发生碰撞时整体回退车的位置和朝向，零件不会被独立推开。没有悬挂、侧翻、轮胎打滑、CCD 或三维脚轮关节求解。凸 Mesh、组过滤和所有权见根目录 MESH_COLLISION.md。

## 验证

`ympme_car_drive` 检查直行、原地旋转、圆弧、脚轮前进/倒车回正、围栏与障碍碰撞、检查点及重置。

`ympme_car_window` 使用 SDL dummy 和真实输入事件检查前进、转向、脚轮摆动、刹车、暂停、重置、相机切换、图像变化与退出。

窗口新增 AABB 次数、粗检测排除数、Mesh 检测数、过滤数，显示最近物理步（含回退重复查询）。

## 模型复用

本 Demo 直接链接 `YMPME::drive`，与三车测试场共用差速运动学；碰撞绑定和检查点仍在场景层。 构建时需启用相应的 `YMPME_MODEL_*` 开关。
