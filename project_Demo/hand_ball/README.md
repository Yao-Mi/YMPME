# 把玩球：低模手、自由刚体球和三维触觉

独立于 `hand_skin` 按压演示。运行 `./build/project_Demo/hand_ball/demo_hand_ball`。初始化自动张手、落球、收拢手指；窗口默认缓慢移动手掌。按 **R** 重新把球放回起点。

## 操作

| 按键 | 动作 |
|---|---|
| F / O | 握紧 / 张手 |
| + / - | 调整手指目标弯曲量（0～100%，不是力控制目标） |
| W | 球实体 / 真实三角网格线框（128 面） |
| M | 缓慢移动、倾斜手腕 |
| J / L、I / K、U / N | 分别移动手腕目标的 X、Y、Z |
| Q / E | 倾斜手腕；张手后倾斜可让球离手 |
| P / C | 给球平移冲量 / 自旋冲量，观察接触和切向摩擦 |
| A | 显示/隐藏方向箭头（RGB 默认关闭） |
| V | GRE 自动 UV / 模型原 UV，对比展开布局 |
| T | RGB 三分量 → 力模长 N → 法向压力 Pa，3D 颜色与 UV 图一起切换 |
| H / B | 皮肤受力颜色 / 骨架 |
| 点击 UV | 查看该面片的力模长及 U、V、N 三分量 |
| Z / G | 球的六维接触力传感器去皮 / 重力开关 |
| 方向键 / 滚轮 | 旋转视角 / 缩放 |
| Space / R / Esc | 暂停 / 重置 / 退出 |

重力朝世界 **-Z**，即向手掌和后方网格平面；网格平面是桌面 `z=-0.06 m`。手腕的移动量、球直径 64 mm、质量 35 g 均按 SI 单位计算。球滚出视野后不会瞬移回来，请按 R。桌面无限大，可视网格只画其中一部分。

## 力图与箭头

默认 **RGB 三分量图**，每个面片按同一标尺编码，不对每帧或每张图自动归一化：

| 通道 | 含义 | 范围与编码 |
|---|---|---|
| R | 法向压缩力 Fn | 0～0.10 N → 0～255 |
| G | 沿当前 UV 的 U 切向力 Fu（右为正） | -0.05～+0.05 N → 0～255，128 表示零 |
| B | 沿当前 UV 的 V 切向力 Fv（下为正） | -0.05～+0.05 N → 0～255，128 表示零 |

**无接触处是 RGB(0,128,128)**，不是黑色。两个切向分量保留符号；纯法向力只改变 R。8 位量化对 G/B 采用 `round(127.5*(1+clamp(F/0.05,-1,1)))`，有半个量化级的零点偏置；点击面片读取的仍是未量化的浮点力。超出显示范围只截断颜色，界面 `RGB clip` 给出受影响面片数，不截断真实物理力。RGB 图是接触载荷可视化，不是皮肤固有颜色。

U/V 基由当前显示的 UV 布局和变形后三角形定义。V 切换自动/源 UV 会同时改变对应切向坐标基，真实世界力不变。UV 每个面片使用原始分量；3D 为邻接面片分量的面积加权平滑示意，自动 UV 接缝处的不同局部坐标可能被平滑。UV 空白区域、选中边框和轮廓是界面标注，采集数据应使用 `forces/taxels` 或 `rgbPatch` 数组，而非截图颜色。

以下模长、压力图和方向箭头仍可切换作对照：


- T 可切换为每个三角面片的三维接触力模长 **|F| = sqrt(Fx²+Fy²+Fz²)**，固定色标 0～0.10 N；不是合力，也不是把 UV 像素数当面积。3D 顶点颜色是邻接面片值的面积加权平滑，UV 面片内是原始值。
- T 也可切换到法向压力（0～1000 Pa），压力按真实变形后的三角形面积计算。读数仍保留完整三维力。
- UV 上每隔 **24 像素**取样，间距固定。无载荷只有灰点；有载荷用高对比白色箭头表示方向，底图颜色继续表示大小。
- UV 箭头采用方向示意约定：纯压缩参考箭头向上，灰色竖线/白参考点是纯法向位置。箭头头部相对参考位置的左右偏移表示 U 切向力，上下偏移表示 V 切向力，位移为 `12*(Fu,Fv)/|F|` 像素。它是将三维分量展开后的读图符号，不是三维向量的唯一二维投影；固定参考长度不编码法向力大小。
- U 向右、V 向下，以当前蒙皮三角形的 UV 导数构造正交切向基；镜像 UV 岛保留它自身的 U/V 方向。N 读数以压缩为正。3D 中同时画出真实世界力方向，箭头尖落在皮肤接触点；方向标注覆盖实体深度以便查看被球挡住的接触侧。
- 同一面片可能覆盖多个 UV 网格采样点，这些箭头重复展示该面片数据，**不能把箭头读数相加当总力**。左侧 `Skin normal total` 才是所有接触面片法向载荷之和。
- Z 只影响球的六维传感器读数，不改变真实力图和物理运动；该传感器测皮肤给球的接触载荷，不含重力、桌面反力。

## GRE 自动展开和复用

直接编译 GRE `project_Demo/scene_baker/scene_uv_atlas.cpp` 及其固定版本 `extern_lib/xatlas/xatlas.cpp`，使用与编辑器相同的 chart/packing 设置、归一化、四像素边距和保持比例的正方形 UV 域。初始化时在张开的绑定姿态生成一次，然后缓存像素→接触面片映射。当前 `hand_low` 生成 **25 个 UV 岛**，512×512 缓存中无重叠像素、无遗漏面片。自动展开仍然有接缝，不会凭空变成一张无缝手掌。

新 UV 保存为面角点坐标，只用于力图。原始 GRE 网格、皮肤贴图 UV、YMSKE 顶点索引、蒙皮权重完全保留；移动手指、切换显示或旋转视角均不重新展开。V 可以直接对照原 UV。初始化需要 C++11 编译器和分配内存，物理/渲染帧内无堆分配。

复用 `hand_skin` 的皮肤面片、受力回传、传感器和 UV 绘制；复用 YMSKE 的 hand_low、骨骼绑定、蒙皮和 PME/GRE bridge；复用 PME RIGID、JOINT、SKIN、TACTILE、FORCE。共享 demo helper 不进入引擎核心，PME 不依赖 GRE/YMSKE，YMSKE/GRE 文件不被修改。

## 物理与限制

球是独立 RIGID 刚体：线速度、角速度、球体惯量、重力、接触力/力矩参与 240 Hz 积分。手腕是有质量的刚体，用 PD 力/力矩跟随用户目标；十五个手指关节用限力矩速度电机控制。皮肤载荷按蒙皮权重分配到骨骼刚体，球获得等大反向载荷，力矩关于相同世界接触点计算。没有球心锁定、吸附或抓取约束。

自由球接触使用新增 `YMPME_SkinContact_SphereRigid`：球面径向压力不产生虚假法向自旋；摩擦使用 `v + omega × r` 的接触点速度并施加对应反向力矩。原 `Sphere` 按压 API 的语义和结构布局不变。

**低面数球是视觉网格，碰撞采用解析球与皮肤面片采样近似。** 不是逐三角形 CCD，也不是软体/FEM；球不变形，手指皮肤随骨骼变形。高速、过深穿透或强力甩手可能丢失接触。当前手模型拇指只有单轴链，尚未实现真实拇指对掌关节。桌面采用弹簧阻尼法向力和受库仑上限约束的黏性摩擦，不含滚动阻力。

## 单独构建

```sh
cmake -S . -B build-hand-ball \
  -DYMPME_BUILD_HAND_BALL_DEMO=ON -DYMPME_BUILD_HAND_SKIN_DEMO=OFF \
  -DYMPME_ENABLE_JOINT=ON -DYMPME_MODEL_SKIN=ON \
  -DYMPME_SENSOR_TACTILE=ON -DYMPME_SENSOR_FORCE=ON \
  -DYMPME_BUILD_GRE_DEMO=ON -DYMPME_GRE_WINDOW=ON \
  -DYMPME_GRE_ROOT=../0502_YMGRE -DYMPME_SKE_ROOT=../YMSKE
cmake --build build-hand-ball --target demo_hand_ball test_hand_ball
ctest --test-dir build-hand-ball -R 'hand_ball|skin_contact' --output-on-failure
```

关闭 `YMPME_BUILD_HAND_BALL_DEMO` 就不编译球 demo 和 xatlas，也不启用 C++。关闭 `YMPME_MODEL_SKIN` 不会改变旧 Body/World ABI；核心、传感器和关节继续单独裁剪。

验证还覆盖 RGB 三通道独立性、正负切向/零点/满量程/超量程编码及实际力图像素对应。其他验证包括：自由落体、接触双向力矩守恒、抓握稳定性、移动时持续接触、松手离开及桌面承重、自旋摩擦耗散、线框/UV切换不改变动力学、自动展开的面片覆盖与拾取、镜像 UV 与上下左右切向方向、旋转坐标不变性、帧内零堆分配和真实按钮/键盘窗口测试。
