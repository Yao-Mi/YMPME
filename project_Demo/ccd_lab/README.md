# CCD 薄墙对照

直接运行 `build/project_Demo/ccd_lab/demo_ccd_lab`，不需要工作目录、模型文件、启动脚本或桌面快捷方式。窗口、输入、时钟全部使用 GRE host；纯物理测试 `test_ccd_lab` 不依赖 GRE。

上方橙球使用离散检测，下方绿球开启球体 CCD。球半径 0.1 m、速度 100 m/s，物理步长 20 ms；薄盒墙厚 20 mm。每步球可移动 2 m，因此离散检测首步会跳到墙后；CCD 在约 8.9 ms 处响应。画面每 0.5 秒推进一个物理步，慢放 25 倍，三步后自动重置；拖尾只连接起点和当前位置，不表示完整反弹路径。黄色箭头表示 CCD 撞击法向。

- 空格：暂停/继续；N：暂停时单步；R：重置。
- B：切换恢复系数 0/1 并重置，观察停住或反弹。
- 1/2/3：静态平面、薄盒子、倾斜凸网格。
- V：球体线框；Esc：退出。

平面为无限单侧平面，图中仅画有限外框。两个通道是独立世界，参数相同，仅 CCD 开关不同。启用恢复后会按剩余步长继续反弹，球可能飞出当前视野，随后自动重置。

构建：启用 `YMPME_ENABLE_DYNAMICS`；窗口另需 `YMPME_BUILD_GRE_DEMO`、`YMPME_GRE_WINDOW` 和 `YMPME_GRE_ROOT`。`--smoke-test` 验证暂停、单步、形状切换、线框、恢复和重置；CTest 使用 GRE 无窗口模式执行。
