# 关节抓取：球、方块和凸 Mesh

直接运行 `build/project_Demo/grasp_lab/demo_grasp_lab`，无需资源文件、脚本或桌面入口，可从任意目录启动；窗口、输入和计时通过 GRE host。

同一套两指机构对照抓取三个 0.30 kg 物体：解析球体、0.4 米方块、16 顶点/28 三角形的削角凸棱柱。后两种显示网格与碰撞几何一致；球以低面数网格显示。均匀密度惯量分别用球公式、盒子公式或棱柱截面面积积分计算，质心/惯量主轴与本地坐标一致。

一个升降滑动关节、两个转动关节和所有接触在 DYNAMICS 中共同求解，物理 240 Hz；物体没有附着到手指。自动夹住、提升、释放、落地，11 秒重置姿态后重复，保留摩擦/电机设置。手指之间、手指与地面被过滤；物体与两指/地面均碰撞。导轨仅为显示模型。

## 操作

| 按键 | 功能 |
|---|---|
| 1 | 单指推球滚动 |
| 2 / 3 / 4 | 抓球 / 方块 / 凸 Mesh，重置到相同实验条件 |
| T | 自动 / 手动 |
| A / D | 手动闭合 / 张开 |
| ↑ / ↓ | 手动升起 / 降下 |
| F | 摩擦 0.85 / 0，观察能否提起 |
| M | 全部电机启停 |
| C | 三维 / 正面 / 侧面 |
| V | 当前物体实体 / 线框 |
| P | 手指 RGB 力图 / 单元平均压力 |
| Space / N | 暂停 / 单物理步 |
| R / Home | 重置当前形状和模式，恢复默认参数 |
| Esc | 关闭 |

也可用 `--box`、`--convex` 直接打开预设。三种网格在窗口初始化时建立，切换不反复分配网格或新建窗口。

## 感知按需添加

只有两根手指内侧各有 8×16 触觉阵列，复用 SurfaceTactile；单元面积在初始化时缓存。被抓物体和地面不带 skin、不做 UV 力图、不创建传感器。右下的物体接触力、力矩直接来自求解器，不是额外感知模型。DYNAMICS 不依赖 SKIN/SENSOR/GRE，开启碰撞不会自动增加感知。

手指 RGB：R 为法向力 0～4 N，G/B 为本地 +Z/+Y 切向力 -2～2 N（128 为零）。暗格未受力，白边标记接触。压力为力/固定单元面积，是单元平均值，不表示材料压陷或真实接触面积；最近格子归集，未人为扩散。

绿色箭头为物体受力，橙色为对方反作用力；黄色标记只显示手指加载单元。`world.contacts[].reactionA/B` 为世界坐标子步平均力/力矩，力矩关于 `originA/B`（子步开始质心）。手指与物体的世界合力成对相反，局部法向分量不必相同。

## 构建与验证

现有 GRE 构建启用 `YMPME_ENABLE_DYNAMICS=ON`、`YMPME_SENSOR_TACTILE=ON`，在 `build` 构建 `demo_grasp_lab`、`test_grasp`、`test_convex_dynamics`。关闭 GRE 后物理测试仍独立运行；关闭 TACTILE 后动力学库仍可单独使用。

三种物体分别验证提升超过 0.35 米、持续双指接触、松开落地、零摩擦提不起来，以及手指触觉合力与求解反馈一致。保留推球滚动测试；GRE 测试实际按键切换三种对象并检查提升与输入行为。

当前为离散检测，凸体最多四点代表流形，没有 CCD、持久接触缓存、跨步热启动或软体材料。凹物体需拆成凸部件，任意渲染三角网格不能直接当作闭合凸碰撞体。
