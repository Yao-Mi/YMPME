# 无人机与老鹰飞行场

两个 GRE 跟随视角观察同一场地：左侧四旋翼，右侧老鹰。打开即自动飞行；HUD 显示高度、空速、升力、推力、垂直速度、四电机 RPM 和翅膀角度。老鹰的振翅和滑翔由真实模型状态驱动显示，位置由载荷积分得到。

运行 `./build/project_Demo/flight_playground/demo_flight_playground`。构建时启用 AIRCRAFT 与其飞行扩展依赖。程序通过 GRE 窗口宿主显示，由 GRE 处理软件显示与 GLX 兼容设置。

| 按键 | 动作 |
| --- | --- |
| Tab | 选择无人机 / 老鹰 |
| T | 自动 / 手动；未选中的对象继续自动飞行 |
| W/S | 无人机前后；鹰调节振翅推力 |
| A/D | 无人机横移；鹰滚转转弯 |
| R/F | 无人机升降；鹰抬头 / 俯冲 |
| Q/E | 无人机偏航；鹰转弯 |
| G | 开关所选对象的电机 / 振翅 |
| V | 阵风开关 |
| C | 跟随、俯视、侧前方三个相机视角 |
| Space / N | 暂停 / 暂停时单物理步 |
| Home | 重置两者位置、开启动力、关闭风；保留当前暂停/操控模式 |
| Esc | 退出 |

观察滑翔：按 Tab 选中老鹰，再按 G；翅膀逐渐展开保持，前向振翅推力归零，仍有翼面升阻力，能量随阻力消耗。再次 G 恢复振翅。无人机的 G 则关闭旋翼并下落，用 Home 恢复。

飞行复用 `YMPME::aircraft → YMPME::flight`；场景使用缓存 GRE 网格。固定 240 Hz 物理推进，过长渲染帧最多补 0.1 s。模型采用游戏近似，只有平面地面支承；树木是视觉参照，不进行机体之间或机体与树木的碰撞。

`demo_flight_playground --smoke-test` 用 GRE 键盘事件检查暂停/单步、手动爬升、对象切换、停翅滑翔、风、视角、自动模式、重置和退出，并检查两幅渲染结果发生变化。

## 独立控制与传感器反馈

启用 IMU、ENCODER、FORCE 三个传感器后，初始无人机由独立控制器驱动。按 **B** 切换外部 PID / 内置控制。左侧第二行显示 IMU 比力、陀螺 Y 轴和机体非重力载荷，第三行显示量化编码器计算的四电机 RPM。外部控制使用理想位姿/速度反馈与 IMU 角速度，尚无纯惯导状态估计。

物理及 IMU/编码器为 240 Hz，独立控制为 120 Hz；`control.c` 和 `control_rig.c` 在无 GRE 环境也可编译测试。关闭 SENSOR 模块时仍能运行原内置控制 Demo，并隐藏 B 提示。传感器细节见 `YMPME/SENSOR/README.md`。
