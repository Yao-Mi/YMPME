# 传感器实验台

运行 `./build/project_Demo/sensor_lab/demo_sensor_lab`。左侧为实际物理场景，中间为2D水平面360°雷达图，右侧为深度图和地面触觉阵列。

- 雷达默认360束、每束1°、20 Hz瞬时单圈。俯视图采用安装坐标：前方+Z朝上，右侧+X朝右。命中点为青色，近障碍遮挡后方，不重复首尾方向。
- 深度相机80×48，内参fx=fy=65、cx=40、cy=24；输出光轴Z深度。暖色近、冷色远、黑色无效；查询来源与雷达相同。
- 地面触觉16×10单元，各单元0.5×1 m。三个重物为1/2/3 kg，稳定总压力合力约58.86 N；额外加载后约88.86 N。热图单元压力按0..180 Pa着色，网格显示为了排版缩放，屏幕长宽不代表单元物理比例。

| 键 | 功能 |
| --- | --- |
| W/A/S/D，Q/E | 移动探头、转向；探头是观测工具，没有车辆动力学 |
| R | 雷达最大量程3 / 12 m |
| I | IMU、编码器、六维测力、雷达、深度的噪声开关 |
| Z | 编码器当前位置设零，下一次测力采样去皮；Home恢复绝对读数 |
| G | 光学查询忽略金色障碍物，物理与可见几何保持原样 |
| F | 每个重物额外施加10 N向下力 |
| B | 把重物抬高后自由落下，观察冲击 |
| C | 顶视 / 立体视角 |
| J | 单点激光投射：关闭 / 点 / 线 / 点＋线，独立于整圈雷达 |
| L | 三维雷达投射：关闭 → 命中点 → 射线 → 点＋线 |
| K | 显示间隔：每束 / 每5束 / 每15束，实际扫描仍为360束 |
| X | 深度遮挡 / 透视调试 |
| Space，N | 暂停 / 单个物理子步 |
| Home，Esc | 重置 / 退出 |

物理、IMU、编码器、六维测力与触觉归集240 Hz，热图每5步输出一次48 Hz时间平均，光学采样20 Hz；不使用渲染帧时间作为物理步长。参数切换会即时重新查询当前姿态。场景边墙为实际实体，GRE同时画出轮廓辅助观察。探头本身在查询中被过滤。当前没有BVH，示例分辨率按可交互成本选取。

触觉直接消费实际World接触冲量，不用预设重力数值生成热图；但接触位置是AABB中心估计，界面明确标记。暂未实现皮肤变形和精确接触压力分布。物理模块、点云、深度图和触觉数组均独立于GRE。

```sh
cmake -S . -B build -DYMPME_BUILD_GRE_DEMO=ON -DYMPME_GRE_ROOT=../0502_YMGRE \
  -DYMPME_ENABLE_QUERY=ON -DYMPME_SENSOR_LIDAR=ON -DYMPME_SENSOR_DEPTH=ON -DYMPME_SENSOR_TACTILE=ON \
  -DYMPME_SENSOR_IMU=ON -DYMPME_SENSOR_ENCODER=ON -DYMPME_SENSOR_FORCE=ON
cmake --build build --target demo_sensor_lab -j
./build/project_Demo/sensor_lab/demo_sensor_lab
```

`--smoke-test` 验证移动、暂停/单步、加载反馈、光学过滤、噪声、量程、视角、重置及改变的渲染帧。

世界视图的GRE相机对接统一为传感器的左右约定，修正原UVN水平轴造成的镜像；同步更新相机基向量和变换矩阵。回归检查顶视/立体两种世界视图中，+X侧金色方块均在-X侧蓝球右侧。世界视图为全局观察，雷达与深度图为探头安装坐标；探头转向后应按各自视角解释方位。

左下显示探头 IMU 比力 ay / 角速度 wy、uint16 单圈编码器与速度、地面测力 Fy 和估计 Tz。WASD/QE 规定探头运动，由实际位移/转角差分生成运动真值；这是可控观测探头，不是完整机器人动力学。静止比力 ay≈9.81 m/s²；IMU 内部三轴都有输出，量程±8g/±8rad/s，量化0.001，低通20Hz。键盘突然启动/停止可能触发加速度限幅。

Force ABS 为向下载荷的正值显示；Z后标注REL，显示相对于去皮时刻的载荷变化。F或B可观察增量/冲击，触觉热图始终显示实际接触载荷。先开噪声再去皮会记录那一次样本的噪声。暂停时校零请求在下一物理步完成。接触力矩仍依赖AABB估计接触点。

上面的构建命令启用全部六种传感器。手动裁剪 IMU/ENCODER/FORCE 后，本窗口仍能构建并显示空间传感器，未启用的读数标为 disabled。新增器件状态与窗口积分缓存预分配在 rig 中，没有逐帧堆分配。左右方向回归保持两个GRE视角和传感器坐标一致。


三维投射默认“点＋线”，每5束显示一束，开启深度遮挡。命中点画青色小十字，命中射线止于最近的几何表面；未命中射线以暗色画到最大量程，末端不画命中点。投射使用采样时的世界坐标起点和终点，因此探头移动/倾斜时不会把旧扫描错误地连到新位置。L/K/X 可在暂停时操作，不触发重新采样。

`lidar_projection.c` 属于 GRE 显示适配层。Demo 在雷达原有查询回调中缓存几何结果，每束只查询一次，渲染只读这些结果；PME 雷达接口和独立编译依赖保持原样。几何投射先于盲区/噪声处理，所以近障碍仍会截断激光；中间雷达图继续显示含噪声的有效传感器读数。被 G 过滤的物体不参与光学查询；默认深度测试仍可能遮住其背后的调试线，可用 X 查看。

新增 `ympme_lidar_projection` 验证四种模式、命中/未命中/盲区、几何起点、显示切换不修改传感器数据且不增加查询次数；窗口 smoke test 验证 L/K/X 实际 GRE 按键路径。


## 单点激光

开启 `-DYMPME_SENSOR_LASER=ON` 后，实验台下方显示单点测距。安装点位于探头本地 +X 方向 0.22 m，激光朝本地 +Z；与探头一起移动/转向。默认量程 0.05～12 m、分辨率 1 mm、20 Hz；R 同时切换单点和整圈雷达的最大量程，I 开启单点 5 mm 标准差的均匀噪声。

单点为粉色射线、黄色命中点，J 独立切换四种显示模式，X 共享深度遮挡开关。L/K 只影响整圈雷达。关闭显示不停止测量；未命中/盲区显示相应状态，不保留上次距离。几何端点直接读测距样本，不再查询场景。

当前预览配置保存在 `build/lidar-preview`；要在主构建中启用此可选模块，执行 `cmake -S . -B build -DYMPME_SENSOR_LASER=ON` 后重新构建 `demo_sensor_lab`。API 和独立构建见 [LASER](../../YMPME/SENSOR/LASER/README.md)。
