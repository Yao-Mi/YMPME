# 齿轮传动：约束 / 紧间距碰撞 / 回差碰撞

从仓库根目录运行 `./build/project_Demo/gear_mesh/demo_gear_mesh`，打开 1260 × 680 的 GRE / YMGUI / SDL 实时对照窗口。三组同时运行，共用电机指令和输出制动负载：

| 左到右 | 模型 | 中心距 | 从动轮如何运动 |
| --- | --- | --- | --- |
| 1 | 理想齿轮约束 | 3.00 m | 由精确 -2/3 角度和速度关系确定 |
| 2 | 紧间距逐齿碰撞 | 3.00 m | 齿面接触冲量改变独立角速度 |
| 3 | 加大间距逐齿碰撞 | 3.08 m | 接触才传力，换向时存在更大的空程 |

每组都是黄色 20 齿主动轮与蓝色 30 齿从动轮。碰撞模型不会强制满足转速比；状态栏显示实际两轴 RPM、齿对接触数、从动轴接触扭矩和传动相位误差。红点标出最近一个外部物理步内的接触位置。

**建议按 T，再按两次 C**：以 4 RPM 每隔 3 秒反向，近看两个碰撞组换齿面时的空程。Space 暂停后，N 单步观察。

| 按键 | 功能（同时作用于三组） |
| --- | --- |
| ↑ / ↓ | 目标转速增减 2 RPM，范围 0–60 RPM |
| R | 反转目标方向，退出自动往返 |
| T | 自动往返开关；开启时重置三组，并使用 4 RPM |
| Space / N | 暂停继续 / 暂停时推进 1/120 秒 |
| C | 斜视 / 俯视 / 啮合区近景 |
| G / V | 分度圆及红色接触点 / 三角线框 |
| M | 电机驱动 / 断电惯性滑行，退出自动往返 |
| Home / Esc | 全部重置为静止、12 RPM 目标 / 退出 |

## 逐齿碰撞的实现

三组共用同一份离散渐开线齿形：每齿 23 个轮廓点，齿顶弧和齿根连接分段近似，再挤出为有厚度的 GRE 网格。几何定义参考 [KHK 齿轮尺寸计算](https://khkgears.net/gear-knowledge/gear-technical-reference/calculation-gear-dimensions/)。齿根未模拟刀具加工的精确过渡曲线，不能作为加工图纸。

碰撞按每个齿分为凸工作齿面片和凸齿根片，先检查每齿 AABB，再做凸片 SAT。对交叠区域做多边形裁剪取得接触位置，以齿面法线和相对于两根轴的力臂计算冲量。法向冲量只能推不能拉；8 轮顺序冲量迭代求解两轴角速度，另做独立的穿透位置修正。

两根轴各自保存并积分角度和角速度，惯量分别为 0.8、2.4 kg·m²。只有主动轴施加限幅 8 N·m 的速度反馈电机扭矩；每根轴有粘性阻力，从动轴另有 0.6 N·m 制动负载。模型内部步长不超过 1/1200 秒。移开齿轮后从动轴没有驱动；给从动轴初速度也可反向驱动主动轴。

紧间距组保留很小的齿厚减薄量和数值间隙，避免两侧齿面同时锁死。回差组只加大中心距，**没有人为添加延迟、死区或转速比跟随代码**。自动化反转测试测得折算到输入轴的换齿面空程约为 **0.31° / 3.33°**；这是当前离散齿形、负载和测试状态的结果，并非普适齿轮参数。相位误差显示为从动轴相对于理想角度的偏差，按一个齿距回绕；它与上述输入轴空程的量纲换算不同。

## 边界

这是固定平行轴、刚性直齿轮的平面接触求解器：两轮沿厚度方向对齐，轴不平移也不倾斜，几何接触使用真实齿形的横截面。只检测两轮之间的齿面，自动排除本轮内部片段。当前 3.00/3.08 m 中心距下，齿顶不会触及另一轮的根圆实体；任意更小中心距或任意凹模型不在支持范围内。

这次新增了应用层的逐齿碰撞和绕固定轴的角冲量，并未把 YMPME 核心改为完整六自由度旋转刚体系统。未实现齿面摩擦、齿弹性、轴承变形、磨损、齿断裂和连续碰撞检测。60 RPM 上限与当前细分时间步共同控制离散穿透。

## 文件与验证

- `gear.c/h`：共享齿形、模式状态、理想约束与电机控制。
- `gear_collision.c`：每齿 AABB、凸片 SAT、交叠裁剪、双轴接触冲量与位置修正。
- `scene.c/h`：共用齿形的 GRE 网格、三视角、接触点显示。
- `main.c`：三组同步窗口、操作与状态读数。
- `test_contact.c`：正反传动、实际反转空程、最高速度不跳齿、移开不传动、输出反驱输入和无电机时动能不增加。

完整 GRE 窗口构建共 18 项测试。`ympme_gear_contact` 测试当前记录的最大离散穿透约 0.000621 m；此值属于测试工况，不是任意状态的全局上界。`ympme_gear_model` 保留齿形/理想约束校验；`ympme_gear_window` 验证三组都出现渲染变化、碰撞组发生接触和反转，以及暂停、单步、自动模式和相机控制。新增碰撞模型通过 ASan/UBSan（未启用 LeakSanitizer）。

## 模型复用

本 Demo 直接链接 `YMPME::gear`；齿形和碰撞求解位于 `MODEL/GEAR`，每实例拥有自己的齿形缓存。 构建时需启用相应的 `YMPME_MODEL_*` 开关。
