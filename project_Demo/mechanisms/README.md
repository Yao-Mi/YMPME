# 皮带、滑轮组与绳端摆动

在 YMPME 根目录运行 `./build/project_Demo/mechanisms/demo_mechanisms`。1200×900 GRE/YMGUI/SDL 原生窗口同时显示四个机构，默认自动往返演示。

| 位置 | 模型 | 观察方式 |
| --- | --- | --- |
| 左上 | 理想无滑动皮带约束 | 两轴同向，角速度比始终为 0.65/0.95 |
| 右上 | 柔性皮带与轮面碰撞、摩擦传动 | 红点为采样接触，显示转速差、摩擦系数和伸长；F 关闭摩擦后从动轮逐渐停转 |
| 左下 | 4:1 理想滑轮组 | 两定滑轮、两动滑轮，四股绳支承 8 kg 重物；手柄走 4 倍行程 |
| 右下 | 无质量绳约束 + 2 kg 质点 | 物体质心从绳子末端初始化，零初速，重力自然产生往返摆动 |

## 操作

- **W/S**：按住提升/下降，进入手动模式。松开后手柄调速器使机构停住；**H** 松开/重新保持手柄。
- **↑/↓**：皮带目标转速；**R** 反向；**M** 电机驱动/断电滑行。左右两皮带接受同样的指令。
- **F**：碰撞皮带摩擦系数 0.85 / 0；**G**：采样接触红点。
- **K**：给摆锤一个切向速度增量。
- **T**：自动/手动。自动模式每 5 秒反转皮带，滑轮组平滑上下运动。
- **Space**：暂停/继续；**N**：暂停时单步；**C**：正视/斜视；**Home**：恢复初始状态和自动演示；**Esc**：退出。

## 动力学与边界

皮带 / 滑轮求解位于 `MODEL/BELT` 和 `MODEL/PULLEY`；摆绳使用 `MODEL/ROPE` 的两节点实例，通过 `mechanisms_model` 和 `Mechanisms_Step` 使用。外部固定步长 1/120 秒，内部细分至不大于 1/600 秒；单独调用三个模型的 Step 函数时，调用方应提供同样的小步长。所有坐标使用米、千克、秒。输入有效区间内模型不动态分配内存。绘制网格只创建一次，后续由局部顶点更新。

**约束皮带**将从动轴惯量、皮带等效惯量与负载反映到主动轴，并严格约束两轴转速比。材质标记沿闭合路径独立累积，不随带轮角度回绕而跳变。

**碰撞皮带**使用 96 个有质量的节点，邻接距离约束采用 24 次 XPBD 迭代，初始约 0.3% 预紧。重力、节点与圆形轮面排斥、库仑切向摩擦共同驱动系统。两轴角速度独立积分，接触对节点施加切向冲量并向带轮施加反向角冲量；从动轴不赋值为传动比。设为零摩擦、从静止运行时，从动轴保持静止，这是测试中的对照项。

这是固定轴、平面、离散节点接触的柔性带近似，非三维 Mesh 碰撞、连续碰撞或完整橡胶材料模型。带段没有自碰撞；预紧、步长、节点数和摩擦都会影响伸长与打滑。UI 调速范围约 ±30 RPM；不作为工业皮带设计计算器。

**滑轮组**使用理想、无摩擦、不可伸长且保持穿绕的连续绳。取向上为正，两个动滑轮随重物共用坐标 `y`，自由端坐标为 `q`，绳长约束为 `4y + q = 常数`。重物和 0.5 kg 手柄在重力、手柄拉力及约束张力下积分；静止悬空时每股绳张力为 `8×9.81/4 = 19.62 N`。手柄拉力读数另扣手柄自重。上下行程限位为演示保护挡块。滑轮旋转标记由绳行程计算。此处采用理想绳长约束，不模拟绳子脱槽和绕轮摩擦。

**悬挂物**以 `position = end`、零速度初始化，初始绳长 2.1 m、倾角约 41.3°。长度约束只受拉、不推压；张力不足时允许松弛。物体按质点计算，球形网格中心就是绳端。显示绳段为锚点到物体的直线，不模拟松弛绳形、绳身质量或与其它物体缠绕；小步长投影存在少量数值阻尼。

这些应用层模型沿用已有 Demo 分层，不向物理核心声明通用旋转刚体/关节能力。未链接飞行扩展；关闭 `YMPME_BUILD_GRE_DEMO` 或 `YMPME_GRE_WINDOW` 时不会编译此目录。

## 验证

`ctest --test-dir build -R ympme_mechanisms --output-on-failure` 包含：

- 摩擦带正反向传动、零摩擦不驱动输出、轮面排斥和长期有限伸长。
- 理想转速比、4:1 绳长/行程、静态张力、提升/释放/限位。
- 绳端初始位置与零速度、往返摆动、最大绳长和无持续增能。
- SDL 事件驱动的四幅渲染变化、暂停/单步、摩擦、反向、提升、相机和重置。

摆绳现在显式链接 `YMPME::rope`。手工构建本 Demo 需 `YMPME_MODEL_ROPE=ON`。具有多节点绳身的下垂 / 运动端点示例见 `rope_lab`。

## 模型复用

皮带、滑轮和摆绳分别链接 `YMPME::belt`、`YMPME::pulley`、`YMPME::rope`；本目录只保留组合与调度。 构建时需启用相应的 `YMPME_MODEL_*` 开关。
