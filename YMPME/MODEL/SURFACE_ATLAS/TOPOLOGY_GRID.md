# 拓扑网格图：一格一面片

`YMPME_TopologyGrid.h` 与 `YMPME::surface_atlas` 一起随 `YMPME_MODEL_SURFACE_ATLAS` 裁剪。纯 C99，不依赖 GRE、SKE、Python、训练框架或堆分配。接收每个三角面片的三个共边邻居（边界为 -1），不读取空间坐标、骨骼分区、动画或力值。

## 方法

1. 在图上对两组固定种子初始化的坐标做惰性扩散，并去均值、正交化。扩散通过多跳连接建立近邻相似性，得到二维平滑嵌入。这是图拉普拉斯低频嵌入的迭代近似，并非精确保存所有最短路距离。
2. 按嵌入坐标递归平衡分配到矩形网格，各子网格容量严格约束面片数量，叶子格最多分配一个面片。
3. 搜索局部及随机全局交换，只有共边邻居的网格距离平方和下降才接受。交换占用者或与空格交换，始终保持一一映射；不直接把多个坐标四舍五入进同一格。

默认 64×64、4000 次扩散、80 轮交换、固定随机种子。人体 3584 面片恰好占用 3584 格，512 格为空，占用率 87.5%。本次构建共边面片平均距离由分配后的约 2.98 格下降到约 1.86 格，约 65.9% 共边关系距离不超过 2 格。二维网格无法保证所有物理邻接都保持，也不能把所有二维邻格视为真实皮肤相邻，智能体可同时读取原始邻接表。

## 接口与存储

`YMPME_TopologyGrid_Build` 输出 `cellToFace[width*height]` 和反向 `faceToCell[faceCount]`，空格为 `UINT32_MAX`。输入边必须互反、不重复，不允许自环；容量不足或输入错误在写输出前返回。调用者提供两份 `2*faceCount` float 坐标和 `faceCount` 个 uint32 排序工作区，约 20 字节/面片，无库内分配。

函数只在初始化或更换拓扑时调用。相同构建、输入、参数和种子可重复；跨平台浮点差异可能影响交换结果，所以应保存最终映射和 `mappingHash`。固定后，动作只更新格子里的力值，不能每帧重新排布。不同物理面积的面片仍各占一格，载荷/压力必须使用真实物理面积。

每格的 RGB 应绑定原面片的固定切向基，不能用格子排列方向重新推断三维受力方向。人体 demo 沿用三角 atlas 的固定切向基，只改变面片存放位置。

验证覆盖一格一面、每面恰好出现一次、反向索引、确定性、有空格、孤立节点/断连分量、非法邻接及容量；人体 demo 另验证全身覆盖、拾取、足部接触与撤离、显示切换不改变原生 64×64 力图。
