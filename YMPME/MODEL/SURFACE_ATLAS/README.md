# 等面积三角形传感器布局

`YMPME_MODEL_SURFACE_ATLAS=ON`，链接 `YMPME::surface_atlas`。默认关闭，纯 C99，只依赖 PME 核心数学，不依赖 GRE、SKE、传感器或堆分配。`YMPME_SurfaceAtlas_Build` 将任意三角网格映射为**等面积、等边长的三角形显示单元**，适合逐面片触觉反馈、传感器分布观察和调试拾取。

这不是保真材质 UV：它主动改变原三角形的形状与面积比例。原模型中很小的手指面片也获得与大胸部面片相同的显示面积；物理面积、受力、压力、采样密度和蒙皮数据均不修改。对同一张图而言，每个三角形面积相等；局部放大的子图有自己的显示缩放和明确量程。

## 展开方法

1. 按位置容差焊接仅用于拓扑查询的重复顶点，消除原 UV 接缝造成的断连；不修改输入网格。默认容差 1 µm，零容差只合并坐标完全相等的点。
2. 排序无向边并建立邻接；非流形边断开，可选 `regions[]` 强制不同区域间切缝。
3. 从未分配的面开始广度优先展开，把相邻三角形沿共同边反射到等边三角格。已经占用的格子不会重复使用；碰到占用位置或图块容量限制时切缝，后续建立新图块。
4. 图块按高度做行式装箱，以统一尺度输出 `[0,1]` 中的逐角点 UV 和图块编号。padding 单位是三角边长，默认 0.35；默认每图块最多 128 面，0 表示不限。

该方法优先保留相邻关系，不保证全局最少接缝。闭合曲面、非六价顶点、分叉和非流形连接通常无法全部铺成连续的等边三角网；因此三角形相等和保留全部邻接不能同时保证。`adjacentEdges/joinedEdges` 提供实际保留比例，`nonManifoldEdges` 记录断开的非流形边；`triangleArea` 是统一 UV 面积，`occupancy` 是所有三角的 UV 面积总和。

## 存储与调用

输入是米制 `pme_vec3 vertices[]`、每面三个 `uint32_t indices[]`、可选每面的区域号；输出是每面六个 float 的 `corners[]` 和 `uint32_t chartIds[]`。

调用者提供 `pme_surface_atlas_workspace`：`canonical[vertexCapacity]`、`queue[faceCapacity]`、`edges[3*faceCapacity]`、`faces[faceCapacity]`、`charts[faceCapacity]`。输入、输出和工作区互不重叠。整个过程没有堆分配；校验失败不写输出，工作区内容不保证保持。结果属于调用者，可缓存用于拾取、绘制和导出。

拓扑焊接当前为 O(V²)，边排序 O(F log F)，图块内占用检查 O(F×每图块面数)，装箱 O(图块数²)。这是初始化/拓扑改变时的操作，不能放到每帧；蒙皮姿态改变后复用 UV。人体 demo 在启动时一次生成单张全身布局，此后仅更新真实力对应的像素颜色。

## 示例与验证

[human_skin](../../../project_Demo/human_skin/README.md) 默认显示单张全身布局，V 可切原 GRE 保比例 UV。颜色仍用真实力（法向 + 两切向），并根据所选显示 UV 建立切向基；图块旋转会改变分量坐标方向，不改变世界力。三角边线是显示标注，不是传感器数据。

测试包括不同物理面积的统一 UV 面积、重复顶点接缝焊接、平面邻接网、闭合四面体、图块限制、区域切缝、非流形边、无重复占格、确定性、容量和错误输入。人体缓存检查所有面片均可拾取且无内部重叠。


## 可选轮廓装箱

在 `Build` 后，使用同一工作区调用 `YMPME_SurfaceAtlas_Compact`。它将带间隙的图块轮廓保守栅格化，再按大轮廓优先、多种画布宽度搜索空位，使小图块填入其他图块的空洞。所有三角形保持原有连接、图块归属、朝向和等面积，不增加接缝；仅当利用率提高时提交布局。不会改变物理网格或载荷。

额外工作内存由调用者提供：两张 `side * ceil(side/64)` 个 uint64 的位图，不在库内分配。每边采样数可取 2～32，画布 side 不超过 4096；容量不足返回错误。此过程只在初始化运行，代价取决于候选位置数及图块轮廓大小，不能放到每帧。

人体配置使用间隙 0.04 边长、每边 12 个采样、960 像素工作画布，额外约 225 KiB 初始化栈空间。保守覆盖每个栅格单元，避免细三角漏检；最终仍通过无重叠、全部面片可拾取验证。全身图的实际面积利用率从此前约 25.6% 提高到约 39.7%，3584 面片和 3499 条保留邻接边不变。布局在启动后固定；改版后的像素位置有变化，智能体使用新导出的面片 ID 图。


可选的 [拓扑网格布局](TOPOLOGY_GRID.md) 支持一面片一格的 2D 图嵌入。人体 demo 现默认使用它，V 可切回轮廓装箱的三角图。两个方法共用此可裁剪模块。
