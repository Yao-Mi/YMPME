# ROPE 对接性能记录

2026-09-12，本机 Linux / GCC 11.4，CMake Release；普通 CPU 绘制路径。数值为单次基准运行的平均值，不是跨平台保证；后台负载、编译优化、迭代数和节点数会影响结果。

`test_rope_gre` 使用 33 节点、32 绳段、256 顶点 / 384 三角形的持久网格。基准强制不同插值 alpha，避免同步缓存命中掩盖实际转换开销。

| 操作 | 本次平均耗时 |
| --- | ---: |
| 直接数组读取并计算位置插值归约 | 0.052 µs |
| 借用 GetView 后做相同插值归约 | 0.046 µs |
| 绳网格同步，含插值、单位转换、顶点、法线和边界 | 9.601 µs |
| 物理外部步进 1/120s，默认 24 次约束迭代 | 186.439 µs |

读取基准各重复 120000 次；几纳秒的差异处于测量噪声范围，不能据此断言视图快于直接读取。两条路径都不复制节点数组。这里只比较同等状态读取工作，没有宣称完整适配层相对任意手写实现“零开销”。

每次实际网格同步写入约 10260 字节（位置、法线、世界中心和包围半径，不计缓存层总线流量）；同 revision / alpha 的重复同步写入为 0。Linux 链接器包装 malloc/calloc/realloc，验证连续步进和同步期间分配次数为 0；网格和三角形索引在 Create 时分配，Destroy 时释放。

真实 GRE 三视图窗口另测得每幅绘制约 0.5ms、同步含端点标记约 12–24µs；此为运行时截图采样，不是独立绘制基准。Demo 每条绳使用 64 次约束迭代，与上表默认 24 次的物理测试不同。Debug 通常更慢，界面会显示本机即时耗时。

复现：Release 配置启用 `YMPME_MODEL_ROPE`、`YMPME_BUILD_ROPE_GRE` 和测试，构建并运行 `test_rope_gre`。仅启用适配层的构建无需 Demo/SDL，`ldd test_rope_gre` 本机只列 libc/libm 和动态加载器。
