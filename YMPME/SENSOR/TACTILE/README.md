# 触觉阵列基础模块

启用 `YMPME_SENSOR_TACTILE=ON`，链接 `YMPME::tactile`。模块把已求解接触载荷归集到平面网格，提供每个单元的法向压力与剪切力，不需要 GRE、雷达或深度相机。

安装坐标的XY平面为皮肤，+Z朝外；网格中心在安装点。`width/height` 为单元数，`cellWidth/cellHeight` 为物理尺寸m，`planeTolerance` 控制接触点允许偏离表面的距离。网格坐标从负X/负Y向正X/正Y增加，外边界采用半开区间。

`YMPME_Tactile_Measure` 接收世界坐标接触点及**作用于皮肤**的力N。压缩力指向本地-Z。点被归入其所在单元，不做虚构的接触面积扩散。输出：

- `cell.force`：安装坐标中的合力；x/y为剪切分量，-z为法向压缩分量。
- `cell.pressure`：`max(0,-force.z)/(cellWidth*cellHeight)`，Pa，表示单元面积平均值。
- `accepted/rejected`：输入贡献项计数；网格外、偏离平面或拉力项会拒绝，计入rejected。
- `totalForce`：已接收贡献项的合力，供核对载荷守恒。
- `approximate`：任一相关输入带近似位置标记时保留。贡献项数不是独立物理接触数量。

`YMPME_Tactile_FromContacts` 可直接接旧 `World_StepWithFeedback`：把本步所有迭代增量冲量按两体受力方向归集，再除以dt。反馈缓冲截断时拒绝输出，避免低估载荷。它反映一个物理子步的平均力；若低频采样要统计整个窗口，应用应连续累积每步单元冲量，不能只抽取某一步当作窗口平均。

**现有World接触点是AABB重叠中心估计。** 因此当前Demo中的触觉位置标为 `AABB ESTIMATE`。重物合力可用于验证承载；单元位置和压力分布不能当作精确皮肤接触。以后有精确接触流形，可直接通过Measure输入相应位置与载荷。

本模块没有皮肤材料弹性、形变、空间扩散、接触面积求解或触觉噪声模型。它提供可复用的阵列采样和数据接口，后续材料模型可以单独组合。参数/容量错误不改输出；计算溢出时帧无效，缓冲可能已写入。缓存由调用者持有，不重叠、不分配内存。

## 连续采样窗口

`YMPME_TactileWindow.h` 使用外部积分缓存逐物理步累积各单元的力×dt和压力×dt，以整个窗口时长归一化。支持变化步长和随体移动的皮肤；输出平均局部分量、窗口末位姿，窗口内保持网格和安装配置一致。丢步、重复步、容量不足、非法帧或溢出拒绝且不修改窗口。输入/积分/输出缓存不能重叠。Read 不清空，Begin 开新窗口。示例在240 Hz物理上每5步输出一次48 Hz热图，详见[公共说明](../README.md#可选器件处理接口)。

## 非平面皮肤传感器

`YMPME_SurfaceTactile.h` 为任意曲面单元提供独立有类型输出，不把曲面展开成旧的XY平面阵列。输入是 `CORE/YMPME_Surface.h` 的世界位置/法线/面积与已经求解的世界接触力，输出每单元总力、切向剪切力、压缩力和压力Pa，以及指定参考点处的总wrench。近似标志由接触提供者传入，输出同样保留时间戳。失败不写输出，使用外部缓存，无堆分配。

此接口不依赖MODEL/SKIN，可直接接更精确的接触流形或其他外部接触算法。旧平面TACTILE和TactileWindow接口不变；SurfaceTactile首版是即时曲面采样，不含自己的低频积分窗口、材料变形或传感器噪声。需要低频输出时应用应逐步积分，不应只抽取一次冲击采样。低模手的球形探头测力另用现有ForceDevice滤波、噪声和去皮。
