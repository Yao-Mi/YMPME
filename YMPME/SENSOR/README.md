# 可裁剪传感器与控制反馈

本层消费 CORE / MODEL 的真值，不推进物理，不依赖 GRE、SDL、AIRCRAFT 或动态分配。直接读真值和模拟传感器两种路径可以并存。公共层提供采样时钟、时间戳、安装变换及可选标量信号处理；每个传感器保留自己的有类型输出，未来点云/深度图不必塞进固定的标量数组。

| 开关（默认 OFF） | 链接目标 | 内容 |
| --- | --- | --- |
| `YMPME_SENSOR_IMU` | `YMPME::imu` | 比力、角速度、安装方向/偏移、固定偏置/噪声、器件量程/量化/滤波 |
| `YMPME_SENSOR_ENCODER` | `YMPME::encoder` | uint16 单圈角度、刻度量化、实际间隔转速、机械零位/反向安装/噪声 |
| `YMPME_SENSOR_FORCE` | `YMPME::force_sensor` | 接触冲量汇总、测力时间窗口、六维安装变换、偏置/噪声/去皮/滤波 |
| `YMPME_SENSOR_LIDAR` | `YMPME::lidar` | [2D 360°雷达](LIDAR/README.md)，距离与安装坐标命中点，单回波 |
| `YMPME_SENSOR_DEPTH` | `YMPME::depth` | [深度相机](DEPTH/README.md)，光轴深度、uint16毫米图、反投影点云 |
| `YMPME_SENSOR_TACTILE` | `YMPME::tactile` | [平面触觉阵列](TACTILE/README.md)，单元平均压力、剪切力、时间平均窗口与近似标志 |

启用任一传感器自动创建 `YMPME::sensor` 公共工具目标；不会自动开启飞行模型、其他传感器或渲染。功能宏仅传递给链接对应目标的消费者。CORE 的 Body/World 布局不因传感器开关变化。

## 真值接口

`CORE/YMPME_Feedback.h` 中 `pme_feedback_state` 使用世界坐标，包含时间、采样间隔、有效位、位置、姿态矩阵、速度、加速度、角速度、角加速度。姿态矩阵表示本体到世界，角度/角速度采用 rad/rad·s⁻¹。

- `YMPME_Aircraft_GetFeedback` 输出飞机状态。加速度与角加速度是完整物理步的速度差分，包含阻力和简化地面约束；初始化后尚无导数时清除导数有效位。
- `YMPME_World_StepWithFeedback` 使用调用方提供的状态/接触缓冲。调用者传入本步结束时刻，逐步调用，以仿真时钟推进。它与普通 Step 得到相同运动状态，并同样清空外力。
- `states[0..stateCount)` 按刚体槽位排列，未激活槽位的 valid=0。旧 World 仍只积分平移，动态体的角速度/角加速度有效位不设置。消费方不能把“不可用”当成零，也不能直接给这样的样本安装 IMU，除非应用明确提供受限运动的角运动真值。
- `contacts[0..count)` 是求解迭代中真正施加的增量冲量，方向作用于 B，A 受反向冲量。应累计所有迭代；不能只保留最后一次迭代。缓冲不足记录 `dropped`，物理继续，测力接口拒绝不完整数据。

接触位置目前采用世界 AABB 重叠区域中心估计，标记 `approximatePoint`；因此力矩标记 `approximateTorque`。这是接触力反馈基础，还不是精确接触流形或皮肤压力分布。JOINT已能单独提供约束反作用载荷，可接ForceSensor的Wrench接口。Body 槽位和接触指针只在本次步进数据生命周期内有效，消费前不得删除/复用目标槽位。

## 采样与交付

`YMPME_SensorClock_Init(period, latency)` 独立配置每个设备。应用先调用 `Due(time)`，满足采样时刻才捕获当前真值，`Stamp` 生成 `time`（捕获时间）和 `availableTime`（允许交付时间）。时刻跳跃时只采当前状态，漏掉的时刻计入 missed；不伪造历史样本。

**公共层不内置延迟队列。** latency 只计算可用时刻；应用须把有类型样本放入自己的有界队列，直到仿真时间达到 availableTime 才交付。当前闭环 Demo 配置零延迟；控制器拒绝未来/过旧 IMU 样本。不同传感器不必共用同一采样率。

模块的 Measure 不自动调度，也不持有外部输出缓冲。固定周期、安装变换、偏置、噪声和数据传输是独立职责。IMU 当前为固定偏置与方差指定的均匀噪声（不是高斯）；每实例独立随机种子，调用顺序固定时可重现。

## 物理含义

IMU 输出安装坐标系的比力 `Rᵀ(a - g)`，不是世界线加速度。安装点偏离质心时，加入 `α×r + ω×(ω×r)`；缺少必要角运动真值时返回错误。静止 Y 向上时读数约 +9.81 m/s²；理想自由落体接近零。IMU 本身不输出姿态；姿态估计应是独立算法。

编码器输入为回绕的机械角度。相邻样本真实转角必须严格小于 π，否则存在混叠，不能可靠计圈。输出 angle 为 uint16_t 单圈码值：0°=0、90°=16384、180°=32768、270°=49152，360°回绕为0。换算为度使用 angle×360/65536，最近刻度舍入；默认65536刻度。首样本角度/时间戳有效，velocityValid=0；后续速度为 rad/s，按单圈码值回绕差与实际时间差计算。

`ForceSensor_Contacts` 输出单物理步的平均接触力，不包含重力与外加驱动力。低采样率请用 `ForceWindow_Begin/Add/Read` 连续累计所有物理步冲量，再除以整个窗口时长；窗口固定世界参考点，漏步/重复步/丢项均返回错误。`ForceSensor_Measure` 则将已知的世界载荷移到安装点并转换坐标；它不从位姿凭空推算关节载荷。

## 无人机闭环示例

原飞行场默认开启独立控制器：物理 240 Hz、IMU/编码器 240 Hz、控制器 120 Hz。位置、速度和姿态来自理想状态反馈；角速度闭环读取带小幅噪声的陀螺仪。加速度、载荷和编码器用于观测展示，不宣称实现纯惯导定位。`control.c` 只接受反馈数据和驾驶指令，不持有物理对象；`control_rig.c` 负责调度和把电机输出交给 `YMPME_Aircraft_StepMotors`。

`StepMotors` 直接接收四电机转速比例 [0,1]，绕过内置控制器与混控，只保留旋翼力学和电机滞后。B 切换独立控制器/原内置控制，两种模式不会同时施加控制。该示例不是硬实时飞控系统。

## 空间传感器与后续扩展

雷达与深度相机共享 `CORE/YMPME_Ray.h` 中的提供者协议，不绑定World。可选 `YMPME_ENABLE_QUERY` 构建 [World射线查询](../CORE/QUERY/README.md)：过滤后AABB筛选，再求Sphere/Box/旋转ConvexMesh实际交点。LiDAR/Depth可各自独立构建，并接应用自己的提供者。方向缓存、点云、深度图、触觉单元均由调用者持有；没有每帧堆分配。

GRE [传感器实验台](../../project_Demo/sensor_lab/README.md) 使用物理240 Hz、光学20 Hz；显示2D完整单圈雷达、深度图和真实重物载荷驱动的触觉热图。

以下能力仍待后续扩展：

- 触觉皮肤：TACTILE已有平面载荷归集；精确接触流形、材料形变、载荷扩散与皮肤响应模型尚未实现。现有World接触位置仍是估计。
- 雷达：当前为2D 360°瞬时单回波扫描；BVH、多回波、反射强度与旋转扫描运动畸变尚未实现。
- 深度相机：已有针孔几何深度与点云；RGB、镜头畸变、滚动快门、立体匹配误差以及GRE深度缓冲提供者尚未实现。

这些设备共享时间戳/安装约定，各自负责数据格式与容量。物理端与渲染端通过适配层连接，避免控制仿真强制启动图形窗口。

## 可选器件处理接口

旧 `IMU_Measure`、`Encoder_Measure`、`ForceSensor_Measure` 的签名与数据布局保持兼容。需要模拟器件时包含对应 `YMPME_IMUDevice.h`、`YMPME_EncoderDevice.h`、`YMPME_ForceDevice.h`，链接原有目标即可，不需要新开关。每个实例拥有自己的滤波状态、随机种子和零位，不修改物理真值；初始化/测量失败不提交设备状态、随机种子或输出。结构体与输出缓冲应互不重叠，设备先 Init 再使用。

`YMPME_Signal.h` 提供六维设备共用的标量处理链：增益/偏移 → 一阶低通 → 量程限制 → 就近刻度量化。`DefaultDesc` 默认直通；`resolution=0` 关闭量化，`cutoffHz=0` 关闭滤波。截止频率单位 Hz，量程/偏移/分辨率与对应通道同单位。状态用 `{0}` 初始化，首样本直接建立基线，后续时间须严格递增。滤波系数按真实时间差计算 `1-exp(-2*pi*f*dt)`；它是离散采样后的一阶滤波，不代替采样前抗混叠滤波。`clipped` 和器件的 `saturated` 表示滤波后超量程，量化后再次夹紧输出；内部滤波值不随输出限幅截断。

IMUDevice 对加速度计/陀螺仪各提供一组处理参数（每轴独立滤波状态），保留原来的逐轴偏置、均匀噪声和安装点运动计算。`saturated` 位0–2为比力XYZ、位3–5为角速度XYZ。它仍不输出融合姿态。

EncoderDevice 增加机械零位 rad、方向 ±1 和角度标准差 rad 的均匀噪声。输出仍是 `uint16_t angle`，差分仍按 `int16_t delta = (int16_t)(now - last);`，now/last 均为 uint16_t。Zero 后首样本 `velocityValid=0`，应用自己的计圈 last 也须重置。若开启测量噪声，零位附近仍可能有小幅抖动。

ForceDevice 输入 `pme_force_sample`：wrench 必须是世界坐标、关于反馈状态质心的载荷。先移到安装点/转换坐标，再加入六轴偏置、力/力矩两组独立均匀噪声；减去零点后执行信号处理。`saturated` 位0–2为力、位3–5为力矩。`approximateTorque` 从输入保留。`TareNext` 在下一次成功测量时记录当前载荷/偏置/噪声并重置滤波；失败仍保留待去皮请求。去皮是相对测量，Init 恢复绝对读数，不改变接触力。可用于关节反作用力，但调用方须先将其参考点/坐标统一为上述约定。

触觉窗口 `TactileWindow_Begin/Add/Read` 使用调用方提供的独立积分缓存，逐单元累计力×dt、压力×dt，Read 除以总时长。漏步、重复步、改变网格大小、无效数据/溢出拒绝且不写窗口；Read 可重复调用，Begin 开新窗口。皮肤可随体移动，平均值是局部随体分量，输出位姿取窗口末端；窗口内网格/安装配置须保持一致。输入、积分、输出单元缓冲不得重叠；无需分配内存。

## 单点激光测距

可选 `YMPME_SENSOR_LASER` / `YMPME::laser` 提供沿安装坐标 +Z 的单射线距离，支持盲区、量程、偏差、均匀噪声及量化。无需开启整圈雷达或 GRE；每次测量仅查询一次，几何结果可供显示层复用。详见 [LASER](LASER/README.md)。
