# 深度相机基础模块

启用 `YMPME_SENSOR_DEPTH=ON`，链接 `YMPME::depth`。针孔相机直接通过射线提供者查询几何，不需要 GRE 渲染窗口；与雷达共享提供者协议，数据格式独立。

内参 `fx/fy/cx/cy` 为像素单位。图像左上角为(0,0)，像素中心为 `(u+.5,v+.5)`；安装坐标 +X 向右、+Y 向上、+Z 向前。`YMPME_Depth_BuildRays` 预计算单位方向，修改内参或分辨率后必须重建缓存；Measure 要求缓存对应当前配置。

`frame.depth[v*width+u]` 是**光轴Z深度，单位米**，不是沿射线的斜距。正对相机的平面应在中心和角落输出相同深度。未命中、盲区或量程外用 `NAN` 表示。支持以Z深度为单位的固定偏置和均匀噪声。

- `YMPME_Depth_Measure`：对同一时刻姿态采集整帧，输出有效时间戳及安装到世界的变换。
- `YMPME_Depth_EncodeU16(frame,1000,...)`：毫米深度图，0表示无效、舍入后为0或超出65535；不把超范围静默饱和成65535。
- `YMPME_Depth_Unproject`：转换为安装坐标点云，与原像素一一对应，无效点为 `(NAN,NAN,NAN)`。

参数/容量错误不改输出。提供者中途错误使输出 `stamp.valid=0,width=height=0`，外部像素缓存可能已部分写入；调用者必须检查返回值。缓存之间不能重叠。所有缓存由调用者持有，模块无动态分配，不提供RGB、镜头畸变、滚动快门、立体匹配或材质相关误差模型。

示例使用80×48，物理20 Hz光学采样；分辨率和内参可配置。当前World提供者逐物体遍历，增加分辨率前应评估查询成本，复杂场景可换用BVH提供者。

射线缓存与内参必须匹配：修改图像尺寸或 fx/fy/cx/cy 后重新调用 BuildRays。Measure 会校验缓存方向与像素斜率，不接受旧缓存静默生成错位图像；此类预检失败不修改输出和随机种子。
