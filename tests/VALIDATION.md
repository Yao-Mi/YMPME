# 0.4.0 本机验证 · 2026-10-09

GCC 11.4、CMake 3.22.1，Linux x86_64。源码模块测试与现有 GRE 离屏配置验证；未逐一手动操作所有窗口，也未进行 MCU 或其他编译器验证。

| 配置 | 结果 | 说明 |
|---|---|---|
| core | 19/19 | Release、核心裁剪 |
| headless | 81/81 | Release、全物理模块、32 位索引 |
| headless16 | 81/81 | Release、全物理模块、16 位索引 |
| sanitize | 81/81 | Debug、ASan/UBSan；错误即失败，未关闭默认泄漏检查 |
| 现有 build | 102/102 | 现有 GRE 离屏示例与模块回归 |

60 秒堆叠（16 次迭代、120/240/480 Hz 切换）：最大高度误差 0.036 mm，最大速度 0.012296 m/s；同一构建的重复初态结果逐位一致。八节关节链（240 Hz、4 次迭代、关节热启动）：最大锚点误差 0.446 mm。数值为本次测试场景的测量，不能推广为任意机构的保证。

新增边界回归拒绝不可表示的极小步长、不能前进的时间及单独刚体溢出，并验证状态不提交。运行方法和阈值见 [README.md](README.md)，历史测试记录见 [HISTORY.md](HISTORY.md)。预编译包独立验证记录在 `build/YMPME_libs/verification/`，其版本、源码摘要和平台信息在 `BUILD_INFO.json`。
