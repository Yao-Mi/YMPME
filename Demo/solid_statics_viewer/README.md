# 立方体 / 块体实体有限元云图

用 GRE 显示真正的三维实体四面体静力结果。实例源码在 `Demo/solid_statics_viewer/`，
可裁剪求解器在 [STATICS / SolidStatics](../../YMPME/STATICS/README-solid.md)。

| 键 | 模型 | 默认加载 |
|---|---|---|
| 1 | 200×200×200 mm 立方体 | x=0 面固定，x=200 mm 面向 -X 均匀受力，总力 1000 N |
| 2 | 400×120×120 mm 块体 | x=0 面固定，x=400 mm 面沿 -Y 均匀受力，总力 1000 N |

材料为 E=70 GPa、nu=0.3 的均匀线弹性材料，没有设置屈服/破坏阈值。
精细立方体有 729 节点、3072 个四面体；粗网格为 125 节点、384 个单元。
块体精细网格有 325 节点、1152 个单元，粗网格为 63 节点、144 个单元。

## 启动

在 PME 根目录运行：

```sh
cmake -S . -B build -DYMPME_ENABLE_SOLID_STATICS=ON -DYMPME_BUILD_SOLID_STATICS_VIEWER=ON -DYMPME_GRE_ROOT=/home/yaomi/文档/0502_YMGRE
cmake --build build --target demo_solid_statics_viewer -j
./build/Demo/solid_statics_viewer/demo_solid_statics_viewer
```

可以直接双击，不安装桌面入口、没有启动脚本、不依赖工作目录。
`--scene 1` / `--scene 2` 指定算例，`--cut` 启动时打开半截切面。
`--shading smooth|element|solid` 指定初始显示方式，默认 `smooth`。
纯数值程序为 `build/demo_solid_statics`，源码为 `Demo/demo_solid_statics.c`。

## 操作

- `1/2`：立方体 / 块体。
- 长按 `A/D` 连续转动、`W/S` 俯仰、`+/-` 缩放，按住 `[/]` 连续调整变形倍率；按实际帧间隔更新，松手或失焦即停止。相机不会随载荷或显示倍率自动漂移。
- `Z` 打开/关闭内部切面，`J/K` 调切面位置；沿参考网格 Z 方向显示整层单元。
- `V` 显示网格边；`M` 切换粗/细网格并重新求解。
- `P` 切换整面与端面右上四分之一区域加载，总力不变。两档网格保持相同加载区域。
- 上/下键：总力 ±250 N（250～4000 N），重新求解。
- `H` 循环切换平滑顶点云图（默认）、原始单元云图、统一蓝色材质。统一颜色时隐藏色条，方便观察形状和变形。
- `C` 循环显示 von Mises 应力、位移模长、应变能密度。
- `L` 用青色标出当前物理量低于全模型最大值 10% 的区域，仅作检查线索。
- `[/]` 调整变形显示倍率；`R` 恢复当前算例；`Esc` 退出。

图例下端为零，上端为当前全模型最大值，右侧列出绝对数值与单位。颜色只表示
相对分布，不表示超过材料许用应力。切面保留全模型色标，便于内外对照。
默认平滑模式按相邻四面体的参考体积加权，将等效应力和应变能密度分别平均到
共享顶点，再在三角形内部插值标量并映射颜色；位移直接使用节点位移模长。
这是显示后处理，不改变求解器或原始单元结果，也不代表计算精度提高。平均值
可能降低局部峰值，因此右侧数值和色标上限始终保留原始结果，按 `H` 可对照
单元原始云图。切片使用同一份全模型节点平均值，转动和切片不会改变数值。

原始模式下应力/应变能为单元常量，位移颜色取单元四节点的位移模长平均。
`L` 的低值区在平滑模式按插值后的数值判定，在原始/统一颜色模式按单元数值判定。
统一颜色时 `L` 仍可覆盖材质显示低值区。亮度按参考面方向变化，保留立方体棱角，
避免放大变形造成逐三角明暗。灰线是未变形包围框，绿色节点表示
固定面。金色轮廓标出实际加载区域，九根等长黄色箭头表示均匀分布力的方向，
不是九个独立的点载荷。箭头附着于加载面变形后的实际位置，并遵守深度遮挡；
转到背面时隐藏，切片移除的部分也隐藏，不把载荷搬到切面。默认视角朝向 X+ 加载面。
加载区域判定与节点力分配共用同一函数，整面/局部载荷保持一致。

切片只是查看内部，不删除材料，也不改变应力结果。删除、挖孔、减薄需要另外
修改几何、重建网格并重新求解。尤其不能仅凭低 von Mises 应力删除材料：还要
检查其他载荷工况、应变能、位移、材料失效模式和稳定性。夹持/载荷边界的峰值
可能对网格敏感；两档网格是收敛检查起点，不代表已达到工程设计精度。

## 结果缓存与交互

位移、单元应力、反力和顶点平均结果保存在内存中。只有模型类型、网格密度、
加载区域或总力实际变化时求解；旋转、缩放、切片、着色、变形倍率和重复选择
同一算例都不重算。右侧 `Solves` 显示本次运行的累计求解次数，便于直接核对。
当前 demo 的材料与固定面不可交互修改；以后扩展这类参数时也需要使缓存失效。

外表面和法线随显示几何变化缓存；旋转每帧只投影一次共享顶点，剔除背面并先
做深度检查。没有操作时保留画面，不重复绘制。表面节点 ID 的排序不代表绕序，
外法线由可见四面体的对顶点恢复，包含切片新暴露的内部面。

运行测试：

```sh
ctest --test-dir build -R 'ympme_solid_statics' --output-on-failure
```

覆盖实体解析基准、位移收敛趋势、全局平衡、应变能，以及窗口切片、换色、
局部载荷、场景切换、网格密度、低值区和三种着色模式切换；验证切回平滑模式
画面恢复一致且原始应力峰值不变，并验证长按连续旋转、松手停止和求解计数不变。
