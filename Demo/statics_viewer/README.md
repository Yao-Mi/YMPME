# 二维静力窗口示例

演示 STATICS 单模块的 7 种二维结构。使用 GRE RenderTarget 与 DemoHost
显示和接收输入；静力库不依赖 GRE，不需要传感器或运动仿真模块。

在 PME 根目录构建（已有 GRE demo 构建只需开启 STATICS）：

```sh
cmake -S . -B build -DYMPME_ENABLE_STATICS=ON -DYMPME_BUILD_STATICS_VIEWER=ON -DYMPME_GRE_ROOT=/home/yaomi/文档/0502_YMGRE
cmake --build build --target demo_statics demo_statics_viewer -j
./build/Demo/statics_viewer/demo_statics_viewer
```

可直接双击可执行文件，不依赖工作目录或外部资源，不安装桌面入口或启动脚本。
纯命令行示例源码位于 `Demo/demo_statics.c`，可执行文件为 `build/demo_statics`。

| 按键 | 算例 | 支承及默认载荷 |
|---|---|---|
| `1` | 悬臂梁 | 左端固支，2 m 梁端 Fy=-10 N |
| `2` | 三角桁架 | 左铰右滚，底边 2 m、高 1 m，顶部 Fy=-10 N |
| `3` | 串联弹簧 | 两个 k=1000 N/m 弹簧，左端固定，其余节点约束 Y，右端 Fx=10 N |
| `4` | 简支梁 | 左铰右滚，2 m 梁跨中 Fy=-10 N |
| `5` | 两跨连续梁 | 总长 4 m、支座在 x=0/2/4，左跨跨中 Fy=-10 N |
| `6` | 门式框架 | 两柱脚固支，宽 2 m、高 1.5 m，右上角 Fx=10 N、Fy=-10 N |
| `7` | Warren 桥式桁架 | 9 节点、15 杆，跨度 4 m、高 1 m，左铰右滚，中部下弦 Fy=-10 N |

梁/框架采用 E=200 GPa、20×40 mm 矩形截面，杆件采用 E=200 GPa、1 mm² 截面。
所有载荷是节点集中力，不包含自动重力或分布载荷。梁共享节点时为刚接。
弹簧是轴向弹簧，图中线圈仅是符号；上下键施加的力由 Y 向导向约束承受。

连续梁右支座默认反力为 -0.9375 N，表示需要抗拔：本算例采用双向位移约束，
相当于带压紧/抗拔装置的理想支承；不是会脱离地面的单向接触支座。
窗口会对这一点显示提示。框架柱脚约束平移与转角。

- 方向键：改变加载节点 Fx/Fy，每次 5 N，分量限制在 ±40 N。
- `+` / `=`、`-`：放大、缩小显示位移；`Tab`：循环选中节点查看位移、转角、反力。
- `R`：重置当前算例；`Esc`：退出。

灰线是原始结构，彩线是放大后的形状，黄色箭头为外力、绿色箭头为支座反力。
箭头方向来自真实力，长度用于示意；反力矩在节点面板中显示。
梁按截面弯矩、桁架按轴力着色，红正蓝负、浅灰为零；右栏显示当前颜色范围。
桁架轴力拉正压负。Tab 选中节点用黄色标记。梁形状使用端点位移和转角的
Hermite 插值。位移显示放大不改变求解结果；这是线性静态平衡，不包含振动。
视区会根据原始结构和放大后的完整曲线自动适配。滚动支座的三角支承、
滚轮及反力箭头跟随变形后的节点；水平轨道保留在参考高度。

```sh
ctest --test-dir build -R 'ympme_statics|ympme_demo_host_boundary' --output-on-failure
```

窗口冒烟测试通过 GRE 注入按键，检查解析挠度、全局力/力矩平衡、画面变化、
7 个算例的载荷调整、场景切换、节点选择、显示倍率、重置和退出。
独立校核包含串联弹簧伸长、简支梁跨中挠度、两跨连续梁三处支反力及桥梁对称反力。

可用 `demo_statics_viewer --scene 1..7` 指定启动算例，默认仍为悬臂梁。

## 连接与反力符号

空心圆表示桁架铰接或梁端的铰支连接；梁柱刚接、连续梁中间节点及固支端
使用实心节点标记。连续梁中间支座不意味着梁在此处断开或释放弯矩。
黄色角括号只表示当前选中节点。

支座的绿色直箭头表示反力，绿色弧形箭头表示反力矩：正值逆时针、负值顺时针；
弧形箭头尺寸仅用于示意，实际力矩值通过 Tab 选中支座后在右侧读取。
门式框架默认变形倍率为 2000，便于观察侧移和弯曲，计算结果不受显示倍率影响。
三角桁架左铰右滚，右端水平可动，因此竖直加载时顶部也会有水平位移。

## 三角桁架：水平拉力在哪里

箭头表示外载荷与支座反力，杆件内力通过颜色和窗口顶部的实时轴力读数显示。
轴力 N 为正（红色）表示受拉，为负（蓝色）表示受压；左右斜杆分别列值，
改变水平载荷后两根斜杆的轴力可以不同。

默认顶点向下 10 N、无水平外载荷时：底杆拉力为 5 N，两根斜杆各承受约
7.07 N 压力。斜杆在底部节点产生向外的水平分力，底杆向内的拉力与之平衡，
所以两端水平支反力为零，竖向支反力各为 5 N。水平支反力为零不等于底杆没有拉力。
这些数值对应默认工况，窗口中的轴力会随方向键调整的载荷实时更新。

当前算例标题用金色高亮，并显示 `1/7` 至 `7/7`。顶部提示共 7 个算例，
按数字键 `1`～`7` 直接切换，不增加选择栏。
