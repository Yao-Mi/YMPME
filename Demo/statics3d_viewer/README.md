# 三维静力 GRE 窗口

独立的三维求解与可交互三维视图，源码位于 `Demo/statics3d_viewer/`。
当前算例金色高亮并显示 `1/3`～`3/3`，直接按数字键切换。

| 键 | 算例 | 默认载荷和支承 |
|---|---|---|
| 1 | 双向弯曲悬臂梁 | X 向长 2 m，根部六自由度固定；端部 Fy=-10 N、Fz=5 N |
| 2 | 空间四杆桁架 | 四个底部节点约束 XYZ 平移、顶部高 1 m；顶部 Fy=-10 N |
| 3 | 扭转悬臂梁 | 根部固定，端部 Mx=3 N·m；默认无平移载荷 |

梁采用半径 15 mm 圆截面、E=200 GPa、G=80 GPa；空间杆截面 1 mm²、E=200 GPa。
第三个算例中可继续加力观察弯扭叠加。桁架没有抗弯/抗扭刚度，因此其力矩键禁用。
这是杆/梁有限元，不是三维实体有限元。所有载荷为节点载荷，无自动重力。

## 运行

在 PME 根目录：

```sh
cmake -S . -B build -DYMPME_ENABLE_STATICS3D=ON -DYMPME_BUILD_STATICS3D_VIEWER=ON -DYMPME_GRE_ROOT=/home/yaomi/文档/0502_YMGRE
cmake --build build --target demo_statics3d_viewer -j
./build/Demo/statics3d_viewer/demo_statics3d_viewer
```

可直接双击运行，不需要启动脚本或特定工作目录。`--scene 1..3` 指定初始算例。
二维窗口保持独立。纯数值例子为 `Demo/demo_statics3d.c`，主构建可执行文件在
`build/demo_statics3d`。模块可单独裁剪，见 [三维库说明](../../YMPME/STATICS/README3D.md)。

## 操作与读图

- `1/2/3`：切换算例；`Tab`：循环查看节点的六自由度位移/转角及反力/力矩。
- 左/右：Fx；下/上：Fy；`Q/E`：Fz。每次 5 N，范围 ±40 N。
- `G/T`：梁的 Mx，每次 1 N·m，范围 ±6 N·m。
- `A/D`：转动视角；`W/S`：调整俯仰；`+/-`：缩放；`C`：重置相机。
- `[/]`：缩小/放大变形，`R`：重置算例，`Esc`：退出。

正交视图的相机固定，修改载荷、变形倍率不会重新居中或取景。固定支座在
屏幕上的位置保持不动，除非主动操作相机或切换算例；极大放大倍率下可手动缩小。
显示对三维线条进行深度比较；世界坐标 +Y 向上，左下角 XYZ 三轴为红/绿/蓝。

黄色箭头是外载荷，绿色为支座反力，弧形箭头表示力矩；箭头尺寸用于示意。
灰线为参考结构，彩线为放大后的变形。空间桁架按轴力着色，红拉蓝压；
第一个梁算例按合成弯矩模长着色，第三个按扭矩正负着色（红正蓝负）。
沿梁的绿/紫十字表示放大后的截面朝向，长度仅为示意，可观察扭转沿梁累积。
纯扭转时中心线不弯曲；右侧转角数值没有放大。显示旋转使用方向标记，求解
仍为小转角线性模型，不包含振动、屈曲、接触、塑性或实体截面应力云图。

测试：`ctest --test-dir build -R 'ympme_statics3d' --output-on-failure`。
窗口冒烟测试通过 GRE 输入事件切换三个算例，检查受力平衡、画面变化、固定端
屏幕位置、视角、节点选择和重置。解析力学验证位于 `tests/test_statics3d.c`。
